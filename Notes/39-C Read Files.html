Introduction to Reading Files 📖

In the previous chapter, we wrote to a file using the w and a modes inside the fopen() function.

To read from a file, you can use the r mode:

FILE *fptr;

// Open a file in read mode
fptr = fopen("filename.txt", "r");

2/7

Reading File Content with fgets() 📄

Next, we need to create a string that should be big enough to store the content of the file.

For example, let's create a string that can store up to 100 characters:

FILE *fptr;

// Open a file in read mode
fptr = fopen("filename.txt", "r");

// Store content of the file
char myString[100];

// Read content and store it inside myString
fgets(myString, 100, fptr);

// Print the file content
printf("%s", myString);

// Close the file
fclose(fptr);

Output: Hello World!

📝 About fgets()

The fgets() function takes three parameters:

  • The first parameter specifies where to store the file content, which will be in the myString array we just created.
  • The second parameter specifies the maximum size of data to read, which should match the size of myString (100).
  • The third parameter requires a file pointer that is used to read the file (fptr in our example).
📝 Note

The fgets() function only reads the first line of the file. If you remember, there were two lines of text in filename.txt.

3/7

Reading Multiple Lines with a Loop 🔄

To read every line of a file, you can use a while loop:

FILE *fptr;

// Open a file in read mode
fptr = fopen("filename.txt", "r");

// Store content of the file
char myString[100];

// Read content and print it
while(fgets(myString, 100, fptr)) {
  printf("%s", myString);
}

// Close the file
fclose(fptr);

Output:

Hello World!

Hi everybody!

💡 Key Concept

The while loop continues until fgets() returns NULL, which happens when the end of the file is reached.

4/7

Handling File Errors ⚠️

If you try to open a file for reading that does not exist, the fopen() function will return NULL.

📌 Good Practice

As a good practice, we can use an if statement to test for NULL, and print some text instead (when the file does not exist):

FILE *fptr;

// Open a file in read mode
fptr = fopen("loremipsum.txt", "r");

// Print some text if file does not exist
if(fptr == NULL) {
  printf("Not able to open file.");
}

// Close the file
fclose(fptr);

Output: Not able to open file.

Good Practices ✅

When working with files in C, following these best practices will help you write more robust and error-free code:

🔍

Check Return Values

Always check the return value of fopen() to ensure the file was opened successfully

📏

Close Files

Always close files when you're done with them to free up system resources

📏

Buffer Size

Use appropriate buffer sizes for reading to avoid truncation

🔒

File Permissions

Make sure your program has the necessary permissions to read/write files

💡 Remember

Proper file handling is essential for many C programs that need to work with persistent data.

Summary 📝

Key Takeaways

  • Use the "r" mode to open files for reading
  • Use fgets() to read strings from files
  • Always check if fopen() returns NULL before trying to read from a file
  • Use a while loop with fgets() to read multiple lines
  • Always close files with fclose() when done

🎯 Best Practices

  • Check return values of file operations
  • Handle errors gracefully with if statements
  • Close files properly to free resources
  • Use appropriate buffer sizes for reading
