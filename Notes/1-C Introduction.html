C Introduction

What is C?

C is a general-purpose programming language created by Dennis Ritchie at Bell Laboratories in 1972.

It is a very popular language, despite being old. The main reason for its popularity is because it is a fundamental language in computer science.

C is strongly associated with UNIX, as it was developed to write the UNIX operating system.

Why Learn C?

  • One of the most popular programming languages in the world.
  • If you know C, learning Java, Python, C++, C# etc. becomes easier since syntax is similar.
  • It helps you understand how computer memory works.
  • C is very fast compared to Java or Python.
  • C is very versatile; used in both applications and technology.

Difference Between C and C++

  • C++ was developed as an extension of C, and both share almost the same syntax.
  • The main difference is that C++ supports classes and objects, while C does not.

Install C

To run C on your computer, you need two things:

  • A text editor (like Notepad) to write C code.
  • A compiler (like GCC) to translate code for the computer.

Install IDE

An IDE (Integrated Development Environment) lets you edit and compile code easily.

  • Popular IDEs: Code::Blocks, Eclipse, Visual Studio.
  • Web-based IDEs work too, but with limited functionality.

We recommend Code::Blocks for beginners.

Download from codeblocks.org and choose mingw-setup.exe to install both the editor and compiler.
