C Booleans ✅❌

Understanding true and false in C programming 🔍

Booleans represent one of two values: true or false ⚖️

1/9

What are Booleans? ❓

Very often, in programming, you will need a data type that can only have one of two values, like:

✅

YES / NO

🔛

ON / OFF

✅ / ❌

TRUE / FALSE

Boolean Type in C 🔧

For this, C has a bool data type, which is known as booleans. Booleans represent one of two values: true or false.

2/9

Boolean Variables 🏷️

In C, the bool type is not a built-in data type, like int or char.

Header File Requirement 📁

It was introduced in C99, and you must import the following header file to use it:

#include <stdbool.h>

Declaring Boolean Variables 📝

A boolean variable is declared with the bool keyword and can take the values true or false:

bool isProgrammingFun = true;
bool isFishTasty = false;
3/9

Printing Boolean Values 🖨️

Before trying to print the boolean variables, you should know that boolean values are returned as integers:

Boolean Representation 🔢

  • 1 (or any other number that is not 0) represents true
  • 0 represents false

Printing Example 💻

Therefore, you must use the %d format specifier to print a boolean value:

// Create boolean variables
bool isProgrammingFun = true;
bool isFishTasty = false;

// Return boolean values
printf("%d", isProgrammingFun); // Returns 1 (true)
printf("%d", isFishTasty); // Returns 0 (false)
Output:
1
0
💡 Important Note

It is more common to return a boolean value by comparing values and variables.

4/9

Comparing Values and Variables ⚖️

Comparing values are useful in programming, because it helps us to find answers and make decisions.

Using Comparison Operators ➕

For example, you can use a comparison operator, such as the greater than (>) operator, to compare two values:

printf("%d", 10 > 9); // Returns 1 (true) because 10 is greater than 9
Output: 1

Comparing Variables 🔄

You can also compare two variables:

int x = 10;
int y = 9;
printf("%d", x > y);
Output: 1
5/9

Comparing Different Values 🔍

In the example below, we use the equal to (==) operator to compare different values:

printf("%d", 10 == 10); // Returns 1 (true), because 10 is equal to 10
printf("%d", 10 == 15); // Returns 0 (false), because 10 is not equal to 15
printf("%d", 5 == 55); // Returns 0 (false) because 5 is not equal to 55
Output:
1
0
0

Comparing Beyond Numbers 🔢➡️🌐

You are not limited to only compare numbers. You can also compare boolean variables, or even special structures, like arrays (which you will learn more about in a later chapter):

bool isHamburgerTasty = true;
bool isPizzaTasty = true;

// Find out if both hamburger and pizza is tasty
printf("%d", isHamburgerTasty == isPizzaTasty);
Output: 1
📝 Remember

Remember to include the <stdbool.h> header file when working with bool variables.

6/9

Real Life Example 🌍

Let's think of a "real life example" where we need to find out if a person is old enough to vote.

Voting Age Check 🗳️

In the example below, we use the >= comparison operator to find out if the age (25) is greater than OR equal to the voting age limit, which is set to 18:

int myAge = 25;
int votingAge = 18;

printf("%d", myAge >= votingAge); // Returns 1 (true), meaning 25 year olds are allowed to vote!
Output: 1
💡 Cool, right?

An even better approach (since we are on a roll now), would be to wrap the code above in an if...else statement, so we can perform different actions depending on the result.

7/9

Using Booleans with if...else 🔀

Output "Old enough to vote!" if myAge is greater than or equal to 18. Otherwise output "Not old enough to vote.":

int myAge = 25;
int votingAge = 18;

if (myAge >= votingAge) {
  printf("Old enough to vote!");
} else {
  printf("Not old enough to vote.");
}
Output: Old enough to vote!

What Happens with Different Ages? 🤔

Let's try with a different age:

int myAge = 16;
int votingAge = 18;

if (myAge >= votingAge) {
  printf("Old enough to vote!");
} else {
  printf("Not old enough to vote.");
}
Output: Not old enough to vote.

Summary 📚

Key Points 🔑

  • Booleans represent one of two values: true or false
  • In C, you need to include the <stdbool.h> header file to use boolean variables
  • Boolean values are represented as integers: 1 (true) and 0 (false)
  • Comparison operators return boolean values
  • Booleans are the basis for all comparisons and conditions
✅

true

Represented by 1 or any non-zero number

❌

false

Represented by 0

⚖️

Comparisons

Return boolean values (1 or 0)

Booleans are the foundation of decision-making in programming! 🎯
