Understanding how to output values and print text in C programming

1/7

Output (Print Text)

To output values or print text in C, you can use the printf() function:

1#include <stdio.h>
2
3int main() {
4  printf("Hello World!");
5  return 0;
6}
Hello World!
🖨️
printf() Function

The printf() function is part of the standard input/output library (stdio.h) and is used to output formatted text to the console.

📚
Library Requirement

You must include the stdio.h header file to use printf()

📝
Function Syntax

printf("text to be printed");

2/7

Double Quotes

When you are working with text, it must be wrapped inside double quotations marks "".

✅
Correct Usage
printf("This sentence will work!");
This sentence will work!
❌ Error Without Quotes

If you forget the double quotes, an error occurs:

printf(This sentence will produce an error.);
error: 'This' undeclared (first use in this function)
error: 'sentence' undeclared (first use in this function)
error: 'will' undeclared (first use in this function)
error: 'produce' undeclared (first use in this function)
error: 'an' undeclared (first use in this function)
error: 'error' undeclared (first use in this function)
💡 Remember

Always wrap text in double quotes "" when using printf() to avoid compilation errors.

3/7

Many printf Functions

You can use as many printf() functions as you want. However, note that it does not insert a new line at the end of the output:

1#include <stdio.h>
2
3int main() {
4  printf("Hello World!");
5  printf("I am learning C.");
6  printf("And it is awesome!");
7  return 0;
8}
Hello World!I am learning C.And it is awesome!
📝 Observation

Notice how all the text appears on a single line without any spaces or new lines between the printf() statements.

🔍
Solution

To make the output more readable, we need to add spaces or new lines manually. We'll learn how to do this in the next slides.

4/7

C New Lines

To insert a new line, you can use the \n character:

1#include <stdio.h>
2
3int main() {
4  printf("Hello World!\n");
5  printf("I am learning C.");
6  return 0;
7}
Hello World!
I am learning C.
📝
Multiple Lines in One printf()

You can also output multiple lines with a single printf() function. However, this could make the code harder to read:

printf("Hello World!\nI am learning C.\nAnd it is awesome!");
Hello World!
I am learning C.
And it is awesome!
5/7

Blank Lines & What is \n

💡 Tip

Two \n characters after each other will create a blank line:

1#include <stdio.h>
2
3int main() {
4  printf("Hello World!\n\n");
5  printf("I am learning C.");
6  return 0;
7}
Hello World!

I am learning C.
❓
What is \n exactly?

The newline character (\n) is called an escape sequence, and it forces the cursor to change its position to the beginning of the next line on the screen. This results in a new line.

6/7

Other Escape Sequences

Examples of other valid escape sequences are:

Escape Sequence Description Example
\n Creates a new line
printf("Line 1\nLine 2");
Line 1
Line 2
\t Creates a horizontal tab
printf("Column 1\tColumn 2");
Column 1        Column 2
\\ Inserts a backslash character (\)
printf("Path: C:\\Folder");
Path: C:\Folder
\" Inserts a double quote character
printf("She said: \"Hello!\"");
She said: "Hello!"

Summary

Escape sequences are special characters that start with a backslash (\) and have special meanings in C strings. They allow you to format output in various ways, including new lines, tabs, and including special characters in your text.
