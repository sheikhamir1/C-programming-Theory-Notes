Function Declaration and Definition 📋

You have already learned from previous chapters that you can create and call a function in following way:

// Create a function
void myFunction() {
  printf("I just got executed!");
}

int main() {
  myFunction(); // call function
  return 0;
}
Declaration

Function's name, return type, and parameters (if any)

Definition

Body of the function (code to be executed)

void myFunction() { // declaration
  // body of function (definition)
}
2/6

Separating Declaration and Definition 🔧

For code optimization, it is recommended to separate declaration and definition of a function.

You will often see C programs that have function declaration above main(), and function definition below main().

This will make code better organized and easier to read:

Recommended Approach
// Function declaration
void myFunction();

// The main method
int main() {
  myFunction(); // call function
  return 0;
}

// Function definition
void myFunction() {
  printf("I just got executed!");
}
💡 Best Practice

Separating declaration and definition makes your code more organized and easier to read. The declaration acts as a preview of what functions are available, while the implementation details are placed separately.

3/6

What About Parameters 📥

If we use example from function parameters chapter regarding parameters and return values:

int myFunction(int x, int y) {
  return x + y;
}

int main() {
  int result = myFunction(5, 3);
  printf("Result is = %d", result);
  return 0;
}
// Outputs 8 (5 + 3)

Output: Result is = 8

It is considered good practice to write it like this instead:

// Function declaration
int myFunction(int x, int y);

// The main method
int main() {
  int result = myFunction(5, 3); // call function
  printf("Result is = %d", result);
  return 0;
}

// Function definition
int myFunction(int x, int y) {
  return x + y;
}
Combined Approach
Declaration + Definition together

Less organized

Separated Approach
Declaration separate from Definition

More organized

4/6

Functions Calling Other Functions 🔄

As long as you declare functions first, it is also possible to use functions to call other functions:

// Declare two functions, myFunction and myOtherFunction
void myFunction();
void myOtherFunction();

int main() {
  myFunction(); // call myFunction (from main)
  return 0;
}

// Define myFunction
void myFunction() {
  printf("Some text in myFunction\n");
  myOtherFunction(); // call myOtherFunction (from myFunction)
}

// Define myOtherFunction
void myOtherFunction() {
  printf("Hey! Some text in myOtherFunction\n");
}

Some text in myFunction

Hey! Some text in myOtherFunction

main() calls myFunction()

↓

myFunction() calls myOtherFunction()

↓

myOtherFunction() executes its code

Summary 📝

Key Takeaways

  • A function consists of two parts: declaration (name, return type, parameters) and definition (body/code)
  • It's recommended to separate function declaration from definition for better code organization
  • Function declarations typically appear above main(), while definitions appear below
  • Functions can call other functions as long as they are declared first
  • Proper function organization makes code more readable and maintainable
