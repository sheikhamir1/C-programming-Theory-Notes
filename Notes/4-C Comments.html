Single-line Comments

Single-line comments start with two forward slashes (//).

Any text between // and the end of the line is ignored by the compiler (will not be executed).

💬
Example 1: Comment Before Code

This example uses a single-line comment before a line of code:

1// This is a comment
2printf("Hello World!");
💬
Example 2: Comment After Code

This example uses a single-line comment at the end of a line of code:

1printf("Hello World!"); // This is a comment
💡 Note

Single-line comments are perfect for brief explanations or notes about specific lines of code.

3/6

C Multi-line Comments

Multi-line comments start with /* and ends with */.

Any text between /* and */ will be ignored by the compiler:

💬
Multi-line Comment Example

This example shows how to use multi-line comments:

1/* The code below will print the words Hello World!
2to the screen, and it is amazing */
3printf("Hello World!");
💬
Multi-line Comment for Code Block

Multi-line comments can also be used to comment out entire blocks of code:

1/*
2printf("This line is commented out");
3printf("This line is also commented out");
4*/
5printf("Only this line will execute");

Single or Multi-line Comments?

It is up to you which you want to use. Normally, we use // for short comments, and /* */ for longer.

Good to Know: Historical Context

📜 C Version History

Before version C99 (released in 1999), you could only use multi-line comments in C.

📅
Evolution of Comments in C

The C programming language has evolved over time, and so has its support for different types of comments:

📜
Pre-C99 Era (Before 1999)

Only multi-line comments (/* */) were supported. This was inherited from the C predecessor, the B programming language.

🆕
C99 and Later (1999+)

Single-line comments (//) were introduced, borrowed from C++. This made C more consistent with its successor language.

💡 Modern C Programming

Today, both comment styles are widely supported. When writing modern C code, consider your audience and the nature of your comments when choosing between // and /* */.

Summary

Comments are an essential part of good programming practice. They help explain your code, make it more readable, and can be used for testing. Whether you prefer single-line (//) or multi-line (/* */) comments depends on your needs and the version of C you're using.
