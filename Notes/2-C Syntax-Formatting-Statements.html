Hello World Example

You have already seen the following code a couple of times in the first chapters. Let's break it down to understand it better:

1#include <stdio.h>
2
3int main() {
4  printf("Hello World!");
5  return 0;
6}
📝 Note

This simple program is the foundation of learning C programming. Let's explore each line to understand what's happening.

2/7

Code Breakdown: Lines 1-3

📚
Line 1: #include <stdio.h>

A header file library that lets us work with input and output functions, such as printf() (used in line 4). Header files add functionality to C programs.

💡 Don't worry if you don't understand how #include <stdio.h> works

Just think of it as something that (almost) always appears in your program.

📄
Line 2: A blank line

C ignores white space. But we use it to make the code more readable.

🚀
Line 3: int main()

Another thing that always appears in a C program is main(). This is called a function. Any code inside its curly brackets {} will be executed.

3/7

Code Breakdown: Lines 4-6

🖨️
Line 4: printf("Hello World!");

printf() is a function used to output/print text to the screen. In our example, it will output "Hello World!".

⚠️ Important

Every C statement ends with a semicolon ;

🔚
Line 5: return 0;

return 0 ends the main() function.

🔐
Line 6: }

Do not forget to add the closing curly bracket } to actually end the main function.

4/7

Code Formatting

📝
Alternative Formatting

The body of int main() could also been written as:

int main(){printf("Hello World!");return 0;}
💡 Remember

The compiler ignores white spaces. However, multiple lines makes the code more readable.

👍

Good Practice

Use proper indentation and line breaks to make your code readable

👎

Bad Practice

Cramming everything into one line makes code hard to understand

5/7

C Statements

📋
What are Statements?

A computer program is a list of "instructions" to be "executed" by a computer.

In a programming language, these programming instructions are called statements.

🖨️
Example Statement

The following statement "instructs" the compiler to print the text "Hello World" to the screen:

printf("Hello World!");
⚠️ Important

It is important that you end the statement with a semicolon ;

6/7

Multiple Statements & Errors

📋
Many Statements

Most C programs contain many statements.

The statements are executed, one by one, in the same order as they are written:

printf("Hello World!");
printf("Have a good day!");
return 0;
🔍
Example Explained

From the example above, we have three statements:

1️⃣
First Statement

printf("Hello World!"); - executed first (print "Hello World!" to the screen)

2️⃣
Second Statement

printf("Have a good day!"); - executed second (print "Have a good day!" to the screen)

3️⃣
Third Statement

return 0; - executed last (end the C program successfully)

❌ Forgetting the Semicolon

If you forget the semicolon (;), an error will occur and the program will not run:

printf("Hello World!")
error: expected ';' before 'return'
