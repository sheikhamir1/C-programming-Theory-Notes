Understanding how to change, copy, and manipulate variable values in C

1/6

Change Variable Values

If you assign a new value to an existing variable, it will overwrite the previous value:

🔄 Overwriting Variable Values
1int myNum = 15; // myNum is 15
2myNum = 10; // Now myNum is 10
Initial Value
myNum = 15
→
New Value
myNum = 10
🔄
Assigning Values Between Variables

You can also assign the value of one variable to another:

1int myNum = 15;
2
3int myOtherNum = 23;
4
5// Assign the value of myOtherNum (23) to myNum
6myNum = myOtherNum;
7
8// myNum is now 23, instead of 15
9printf("%d", myNum);
23

Copy Values to Empty Variables

You can also copy values to empty variables:

📋
Copying to Empty Variables

This example shows how to copy a value from an initialized variable to an uninitialized one:

1// Create a variable and assign the value 15 to it
2int myNum = 15;
3
4// Declare a variable without assigning it a value
5int myOtherNum;
6
7// Assign the value of myNum to myOtherNum
8myOtherNum = myNum;
9
10// myOtherNum now has 15 as a value
11printf("%d", myOtherNum);
15
Source
myNum = 15
→
Destination
myOtherNum = ?
→
Result
myOtherNum = 15
💡 Tip

When copying values, the original variable retains its value. You're creating a copy, not moving the value.

Add Variables Together

To add a variable to another variable, you can use the + operator:

➕ Adding Variables
1int x = 5;
2int y = 6;
3int sum = x + y;
4printf("%d", sum);

4/6

Declare Multiple Variables

To declare more than one variable of the same type, use a comma-separated list:

📝 Declaring Multiple Variables with Initial Values
1int x = 5, y = 6, z = 50;
2printf("%d", x + y + z);
61
🔄
Assigning Same Value to Multiple Variables

You can also assign the same value to multiple variables of the same type:

1int x, y, z;
2x = y = z = 50;
3printf("%d", x + y + z);
150
x
50
y
50
z
50
💡 Note

When using chained assignment (x = y = z = 50), the value is assigned from right to left. First, z gets 50, then y gets the value of z (50), and finally x gets the value of y (50).
