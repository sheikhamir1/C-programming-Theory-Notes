Strings 📝

Strings are used for storing text/characters.

Example 💻

For example, "Hello World" is a string of characters.

char greetings[] = "Hello World!";
2/11

Creating Strings 📝

In C, you must use the char type and create an array of characters to make a string.

Using String Literal "

The easiest way to create a string in C is by using a string literal in double quotes:

char greetings[] = "Hello World!";

Using Character Array { }

Another way is to create a string with a set of characters. This example will produce the same result as the example in the beginning of this page:

char greetings[] = {'H', 'e', 'l', 'l', 'o', ' ', 'W', 'o', 'r', 'l', 'd', '!', '\0'};
💡 Important Note

Why do we include the '\0' character at the end? This is known as the "null terminating character", and must be included when creating strings using this method. It tells C that this is the end of the string.

3/11

Accessing Strings 🔍

Since strings are actually arrays in C, you can access a string by referring to its index number inside square brackets [].

Example 💻

This example prints the first character (0) in greetings:

char greetings[] = "Hello World!";

printf("%c", greetings[0]); // Outputs H
Output: H
💡 Indexing

Remember that: Array indexes start with 0: [0] is the first element. [1] is the second element, etc.

4/11

Modify Strings ✏️

To change the value of a specific character in a string, refer to its index number, and use single quotes:

Example 💻

This example changes the first character (0) from 'H' to 'J':

char greetings[] = "Hello World!";

greetings[0] = 'J';

printf("%s", greetings); // Outputs Jello World!
Output: Jello World!

Loop Through a String 🔄

You can also loop through the characters of a string, using a for loop:

Example 💻

This example loops through each character in the string "Volvo":

char carName[] = "Volvo";

int i;

for (i = 0; i < 5; ++i) {
  printf("%c\n", carName[i]);
}
Output:
V
o
l
v
o

Better Loops ⚡

Like we specified in the arrays loop chapter, you should use the sizeof formula (instead of manually writing the size of the array in the loop condition) to make the loop more sustainable:

char carName[] = "Volvo";

int length = sizeof(carName) / sizeof(carName[0]);

int i;

for (i = 0; i < length; ++i) {
  printf("%c\n", carName[i]);
}
Output:
V
o
l
v
o
💡 Best Practice

Summary: Always use the sizeof formula when looping through strings. It makes your loops adapt to the string size automatically.

Real-Life Examples 🌍

Use strings to create simple welcome messages or handle user names:

Welcome Message 👋

This example creates a simple welcome message with a name:

char message[] = "Good to see you, ";

char fname[] = "John";

printf("%s %s!", message, fname);
Output: Good to see you, John!

Personalized Greeting 👤

This example creates different greetings based on the time of day:

char greeting;

// Get current hour (24-hour format)
int hour;

time(&hour);

if (hour < 12) {
  greeting = "Good morning, ";
} else if (hour < 18) {
  greeting = "Good afternoon, ";
}

else {
  greeting = "Good evening, ";
}

printf("%s", greeting);
Output: Depends on the current time of day

String Functions 🔧

C also has many useful string functions, which can be used to perform certain operations on strings.

String Length 📏

For example, to get the length of a string, you can use the strlen() function:

char alphabet[] = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";

printf("%zu", strlen(alphabet));
Output: 26
💡 Size vs. Length

Note that sizeof and strlen behave differently, as sizeof also includes the \0 character when counting:

char alphabet[] = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";

printf("%zu\n", strlen(alphabet)); // 26
printf("%zu\n", strlen(alphabet)); // 27
Output: 27

Special Characters and Escape Sequences 🔠

Because strings must be written within quotes, C will misunderstand this string and generate an error. The solution is to use escape characters:

Escape Character Result Try it
\\ Backslash Single quote printf("This is a backslash: \\");
\" Double quote printf("This is a double quote: \"");
\\ Backslash printf("This is a backslash followed by a newline: \\n");
\t Tab printf("This is a tab: \t");
\0 Null printf("This is a null character: \0");
