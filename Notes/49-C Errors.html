Common Compile-Time Errors 🔧

What Are Compile-Time Errors?

Compile-time errors are mistakes that prevent your program from compiling. These are syntax errors or other issues that the compiler detects before your program can run.

1️⃣ Missing Semicolon
#include <stdio.h>

int main() {
  int x = 5
  printf("%d", x);
  return 0;
}
error: expected ',' or ';' before 'printf'
3/10

More Compile-Time Errors 🔧

2️⃣ Using Undeclared Variables
#include <stdio.h>

int main() {
  printf("%d", myVar);
  return 0;
}
error: 'myVar' undeclared
3️⃣ Mismatched Types
#include <stdio.h>

int main() {
  int x = "Hello";
  return 0;
}
error: initialization makes integer from pointer without a cast

Common Runtime Errors 💥

What Are Runtime Errors?

Runtime errors occur when the program compiles but crashes or behaves unexpectedly. These errors are often harder to spot because they don't appear until the program is running.

1️⃣ Dividing by Zero
#include <stdio.h>

int main() {
  int x = 10;
  int y = 0;
  int result = x / y;
  printf("%d\\n", result); // not possible
  return 0;
}
5/10

More Runtime Errors 💥

2️⃣ Accessing Out-of-Bounds Array Elements
#include <stdio.h>

int main() {
  int numbers[3] = {1, 2, 3};
  printf("%d\\n", numbers[8]); // element does not exist
  return 0;
}
3️⃣ Using Freed Memory
#include <stdio.h>
#include <stdlib.h>

int main() {
  int* ptr = malloc(sizeof(int));
  *ptr = 10;
  free(ptr);
  printf("%d\\n", *ptr); // Undefined behavior
  return 0;
}

Good Habits to Avoid Errors ✅

Developing Good Programming Practices

Adopting good habits can significantly reduce the number of errors in your code and make debugging much easier.

🔧
Initialize Variables

Always initialize your variables to avoid undefined behavior.

📝
Meaningful Names

Use meaningful variable names to make your code more readable.

🧹
Clean Code

Keep your code clean and use indentation to stay organized.

More Good Habits ✅

🔍

📖
Read Error Messages

Read error messages carefully - they often tell you exactly where the problem is.

Error Prevention Tips 🛡️

Proactive Error Prevention

The best way to deal with errors is to prevent them from happening in the first place. Here are some additional tips:

📝

Comment Your Code

Add comments to explain complex parts of your code

🧪

Test Frequently

Test your code as you write it to catch errors early

📚

Learn From Mistakes

Understand why errors happen to avoid repeating them

🔍
Debugging Mindset
When you encounter an error, approach it systematically. Read the error message, identify the location, understand the cause, and then fix it.
