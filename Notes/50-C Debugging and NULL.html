Debugging 🐛

What is Debugging?

Debugging is the process of finding and fixing errors (bugs) in your program.

Bugs are mistakes that make your program crash, behave incorrectly, or give the wrong output.

🧹
Before You Start Debugging
  • Use proper indentation to keep the structure clear
  • Give your variables clear, meaningful names that describe what they store
  • Clean code is easier to read - and easier to debug!
💡
Key Insight

The time you spend writing clean, organized code will save you hours of debugging later.

Print Debugging 🖨️

1️⃣ Use printf() to Trace Your Code

Use printf() to print values at different points in your code to see what's going wrong:

int x = 10;
int y = 0;
printf("Before division\n"); // Debug output
int z = x / y; // Crashes (division by zero)
printf("After division\n"); // Never runs

If you don't see "After division", the program crashed at x / y.

Print variables to see if they are what you expect:

Debugging with Safe Checks 🛡️

Preventing Crashes Before They Happen

Some bugs, like dividing by zero, are known to cause crashes. If you know an operation could fail, you can check for it in advance and avoid the crash.

Division by Zero Example
int main() {
  int x = 10;
  int y = 0;

  printf("Before division\n");

  if (y != 0) { // Check that y is not zero before dividing
    int z = x / y;
    printf("Result: %d\n", z);
  } else {
    printf("Error: Division by zero!\n"); // Print error message instead of crashing
  }

  printf("After division\n");
  return 0;
}
💡
Result
Now, instead of crashing, the program prints an error message and continues running. This is an important part of writing safe, debuggable code.

Out-of-Bounds Array Access 📊

Another Common Mistake

Accessing elements outside the array is another common mistake. In the example below, we use printf() to check the index value before using it:

Safe Array Access Example
int main() {
  int numbers[3] = {10, 20, 30};
  int index = 5;

  printf("Index = %d\n", index);
  if (index >= 0 && index < 3) { // Make sure the index is within the valid range (0 to 2)
    printf("Value = %d\n", numbers[index]);
  } else {
    printf("Error: Index out of bounds!\n");
  }

  return 0;
}

C NULL 🚫

What is NULL?

NULL is a special value that represents a "null pointer" - a pointer that does not point to anything.

It helps you avoid using pointers that are empty or invalid. You can compare a pointer to NULL to check if it is safe to use.

Valid Pointer

Points to memory

≠

NULL Pointer

Points to nothing

💡
Common Usage

Many C functions return NULL when something goes wrong. For example, fopen() returns NULL if a file cannot be opened, and malloc() returns NULL if memory allocation fails.

10/12

NULL Examples 💻

File Opening Example

In this example, we try to open a file that does not exist. Since fopen() fails, it returns NULL and we print an error message:

#include <stdio.h>

int main() {
  FILE *fptr = fopen("nothing.txt", "r");

  if (fptr == NULL) {
    printf("Could not open file.\n");
    return 1;
  }

  fclose(fptr);
  return 0;
}
Memory Allocation Example

If you try to allocate too much memory, malloc() may fail and return NULL:

#include <stdio.h>
#include <stdlib.h>

int main() {
  int *numbers = (int*) malloc(100000000000000 * sizeof(int));

  if (numbers == NULL) {
    printf("Memory allocation failed.\n");
    return 1;
  }

  printf("Memory allocation successful!\n");

  free(numbers);
  numbers = NULL;

  return 0;
}
11/12

NULL Summary 📝

Key Takeaways

  • NULL represents a null (empty) pointer
  • It signals that a pointer is not pointing anywhere
  • You can compare a pointer to NULL to check if it's safe to use
  • Functions like malloc() and fopen() return NULL if they fail
💡
Important Tip
Always check if a pointer is NULL before using it. This helps avoid crashes caused by accessing invalid memory.
