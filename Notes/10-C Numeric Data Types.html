Numeric Types

Use int when you need to store a whole number without decimals, like 35 or 1000, and float or double when you need a floating point number (with decimals), like 9.99 or 3.14515.

🔢

int

Whole numbers
without decimals

int myNum = 1000;
printf("%d", myNum);
1000
🔢

float

Floating point numbers
with decimals

float myNum = 5.75;
printf("%f", myNum);
5.750000
🔢

double

Floating point numbers
with higher precision

double myNum = 19.99;
printf("%lf", myNum);
19.990000
💡
When to Use Each Type
🔢
int

Use for whole numbers, counting, indexing, and when decimal precision is not needed

🔢
float

Use for floating point numbers when memory is a concern and high precision is not critical

🔢
double

Use for floating point numbers when precision is important and memory usage is not a concern

2/6

float vs. double

The precision of a floating point value indicates how many digits the value can have after the decimal point. The precision of float is six or seven decimal digits, while double variables have a precision of about 15 digits.

Aspect float double
Precision 6-7 decimal digits ~15 decimal digits
Memory Usage 4 bytes 8 bytes
Format Specifier %f %lf
Best For Memory-constrained applications Most calculations requiring precision
💡 Recommendation

It is often safer to use double for most calculations - but note that it takes up twice as much memory as float (8 bytes vs. 4 bytes).

Scientific Numbers

In C, you can write very large or very small floating-point numbers using scientific notation.

This is done using the letter e (or E), which stands for "times 10 to the power of".

For example, 35e3 means 35 × 10³ = 35000.

Scientific Notation
35e3
→
Mathematical Form
35 × 10³
→
Result
35000
🔬
Scientific Notation Examples

This is useful for writing numbers in a shorter way. Especially when working with scientific values or large-scale data.

1float f1 = 35e3; // 35 * 10^3 = 35000
2double d1 = 12E4; // 12 * 10^4 = 120000
3
4printf("%f\n", f1);

4/6

C Decimal Precision

You have probably already noticed that if you print a floating point number, the output will show many digits after the decimal point:

1float myFloatNum = 3.5;
2double myDoubleNum = 19.99;
3
4printf("%f\n", myFloatNum); // Outputs 3.500000
5printf("%lf", myDoubleNum); // Outputs 19.990000
3.500000
19.990000
🎯
Set Decimal Precision

If you want to remove the extra zeros (set decimal precision), you can use a dot (.) followed by a number that specifies how many digits that should be shown after the decimal point:

1float myFloatNum = 3.5;
2
3printf("%f\n", myFloatNum); // Default will show 6 digits after the decimal point
4printf("%.1f\n", myFloatNum); // Only show 1 digit
5printf("%.2f\n", myFloatNum); // Only show 2 digits
6printf("%.4f", myFloatNum); // Only show 4 digits
