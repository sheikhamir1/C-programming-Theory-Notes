Nested Structures 📊

A structure can also contain another structure as a member. This is called a nested structure.

This is useful when you want to group related data together, for example, a person with their name, age, and address.

Outer Structure

struct Person {
  char firstName[30];
  char lastName[30];
  int age;
  char address[100];
};
→

Inner Structure

struct Owner {
  char firstName[30];
  char lastName[30];
  int age;
  char address[100];
};
2/5

Creating Nested Structures 🏗️

Here's how to create a nested structure:

struct Person {
  char firstName[30];
  char lastName[30];
  int age;
  char address[100];
};
  struct Owner owner;
  char firstName[30];
  int age;
};

int main() {
  struct Person person;
  person.firstName = "John";
  person.lastName = "Doe";
  person.age = 30;
  strcpy(person.firstName, "Jane");
  strcpy(person.lastName, "Smith");
  person.age = 25;
  strcpy(person.address, "123 Main St");
  // Print values
  printf("Name: %s, Age: %d\n", person.firstName, person.age);
  printf("Owner: %s, Age: %d\n", person.owner.firstName, person.owner.lastName);
  printf("Name: %s, Age: %d\n", owner.firstName, owner.lastName);
  printf("Name: %s, Age: %d\n", person.firstName, person.age);
  printf("Name: %s, Age: %d\n", person.firstName, person.lastName);
  printf("Name: %s, Age: %d\n", person.firstName, person.age);
  printf("Name: %s, Age: %d\n", person.firstName, person.age);
  printf("Name: %s, Age: %d\n", person.firstName, person.age);
  // Print values
  printf("Name: %s, Age: %d\n", person.firstName, person.age);
  // Return success
  return 0;
}
}

💡 Key Concept

Nested structures allow you to organize related data in a hierarchical way, making your code more readable and maintainable.

Accessing Nested Structure Members 🔑

To access members of a nested structure, you use multiple dot operators:

struct Person {
  char firstName[30];
  char lastName[30];
  int age;
  char address[100];
};

int main() {
  struct Person person;
  person.firstName = "John";
  person.lastName = "Doe";
  person.age = 30;
  char address[100];
  // Access firstName
  printf("First Name: %s\n", person.firstName);
  // Access lastName
  printf("Last Name: %s\n", person.lastName);
  // Access age
  printf("Age: %d\n", person.age);
  // Access address
  printf("Address: %s\n", person.address);
  // Return success
  return 0;
}
💡 Dot Operator

The first dot accesses the member directly.

The second dot accesses the member inside the nested structure.

4/5

Pointers to Structures 👉

You can use pointers with structures to make your code more efficient, especially when passing large structures to functions.

void printPerson(struct Person *person) {
  // Print values
  printf("Name: %s, Age: %d\n", person->firstName, person->age);
  // Modify age
  person->age = 35;
}
}

int main() {
  struct Person person;
  person.firstName = "Alice";
  person.lastName = "Smith";
  person.age = 28;
  char address[100];
  char address[100];
  int printPerson(struct Person *person) {
  // Print values
  printf("Name: %s, Age: %d\n", person->firstName, person->age);
  printf("Name: %s, Age: %d\n", person->firstName, person->age);
  // Modify age
  person->age = 35;
  // Print updated age
  printf("Updated Age: %d\n", person->age);
  // Return success
  return 0;
}
}
💡 Benefits

Using pointers with structures:

  • Avoids passing by reference instead of value
  • More efficient - no copying of data
  • Can modify original structure
  • Less memory usage

💡 Real-World Application

Nested structures are commonly used in:

  • Database systems (storing records with multiple fields)
  • GUI applications (with complex UI components)
  • Game development (player/enemy data)
  • Embedded systems (microcontrollers)

Benefits of Nested Structures 🎯

Nested structures provide several advantages:

  • Logical organization of related data
  • Code readability and maintainability
  • Reduced parameter passing
  • Memory efficiency
  • Easier data management
💡 Key Takeaway

Use nested structures when you have related data that naturally forms hierarchies.

Summary 📝

Key Takeaways

  • Structures can contain other structures as members
  • Use dot notation to access nested members
  • Pointers are efficient for large structures
  • Use nested structures for hierarchical data

🎯 Best Practices

  • Use meaningful names for structures and members
  • Document your nested structures
  • Initialize all members
  • Consider using pointers for large structures
