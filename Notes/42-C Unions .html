Unions 🔗️

A union is similar to a struct, but with one key difference:

In a struct, each member has its own memory location.

In a union, all members share the same memory location.

This means you can only use one member at a time.

💡 Key Concept

Unions are particularly useful when you need to store different data types in the same memory location.

2/7

Declaring a Union 📋

The syntax for declaring a union is similar to a struct:

union // Union declaration
union myUnion {
int i;
char c;
float f;
};
💡 Key Point

The keyword 'union' is used instead of 'struct' when declaring a union.

Using a Union 🔄

Here's how to use a union:

union myUnion {
int i;
char c;
float f;
union u;
  u1.c = 'A';
  // Assign a value to c
u1.c = 'A';
  union u1.c = 'B';
  // Now both u1 and u2 hold different values
  // Print values
  printf("Value 1: %c\n", u1.c);
  printf("Value 1: %c\n", u1.c);
  printf("Value 2: %c\n", u2.c);
  // Print values
  printf("Value 1: %c\n", u1.c);
  printf("Value 2: %c\n", u2.c);
  // Print values

  // Print values
  printf("Value 1: %c\n", u1.c);
  printf("Value 2: %c\n", u2.c);
  return 0;
}
}

Benefits of Unions 🎯

Unions provide several advantages:

  • Memory efficiency - unions use the same memory for different data types
  • Flexibility - Store different data types in the same memory location
  • Memory efficiency - No wasted memory for small data types
  • Type flexibility - Can store different types in the same memory location
  • Compact storage - Multiple values in one memory location
💡 Key Concept

Unions are particularly useful in:

Summary 📝

Key Takeaways

  • Unions store different data types in the same memory location
  • Use unions for memory efficiency
  • Unions are particularly useful in embedded systems
  • Great for bit manipulation and low-level programming

🎯 Best Practices

  • Always initialize all members before use
  • Be clear about which member holds which value
  • Document your union with comments
  • Use meaningful member names
