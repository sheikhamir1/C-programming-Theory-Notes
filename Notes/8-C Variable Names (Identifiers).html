C Variable Names

All C variables must be identified with unique names.

These unique names are called identifiers.

🏷️
Identifier Types

Identifiers can be short names (like x and y) or more descriptive names (age, sum, totalVolume).

💡 Note

It is recommended to use descriptive names in order to create understandable and maintainable code:

Good Variable Name
int minutesPerHour = 60;
✅

Clear and descriptive

VS
VS
Not So Good
int m = 60;
⚠️

OK, but not so easy to understand what m actually is

2/7

Rules for Naming Variables

The general rules for naming variables are:

Rule Valid Examples Invalid Examples
Names can contain letters, digits and underscores myVar, var1, _temp my-var, var#1
Names must begin with a letter or an underscore (_) name, _name, _123 1name, 123
Names are case-sensitive myVar and myvar are different variables None
Names cannot contain whitespaces or special characters myVar, my_var my var, my@var
Reserved words cannot be used as names myInt, myNumber int, float, char
⚠️ Important

Reserved words (such as int) cannot be used as names. These words have special meaning in C and are part of the language syntax.

3/7

Naming Conventions

While C doesn't enforce specific naming conventions, following common practices makes your code more readable:

🐪

camelCase

firstName, lastName, studentAge

🐍

snake_case

first_name, last_name, student_age

🔤

PascalCase

FirstName, LastName, StudentAge

💡
Best Practices
📝
Be Descriptive

Choose names that describe the purpose of the variable

📏
Keep it Reasonable

Avoid extremely long names that make code hard to read

🔄
Be Consistent

Stick to one naming convention throughout your program

Real-Life Example: Student Data

Often in our examples, we simplify variable names to match their data type (myInt or myNum for int types, myChar for char types, and so on). This is done to avoid confusion.

However, for a practical example of using variables, we have created a program that stores different data about a college student:

🎓 Student Data Example
1// Student data
2int studentID = 15;
3int studentAge = 23;
4float studentFee = 75.25;
5char studentGrade = 'B';
6
7// Print variables
8printf("Student id: %d\n", studentID);
9printf("Student age: %d\n", studentAge);
10printf("Student fee: %f\n", studentFee);
11printf("Student grade: %c", studentGrade);
Student id: 15
Student age: 23
Student fee: 75.250000
Student grade: B
💡 Tip

Notice how the variable names (studentID, studentAge, etc.) clearly describe what data they store. This makes the code much easier to understand and maintain.

Calculate the Area of a Rectangle

In this real-life example, we create a program to calculate the area of a rectangle (by multiplying the length and width):

📐 Rectangle Area Calculation
1// Create integer variables
2int length = 4;
3int width = 6;
4int area;
5
6// Calculate the area of a rectangle
7area = length * width;
8
9// Print the variables
10printf("Length is: %d\n", length);
11printf("Width is: %d\n", width);
12printf("Area of the rectangle is: %d", area);
Length is: 4
Width is: 6
Area of the rectangle is: 24
width = 6
length = 4
Rectangle
Area = 24
💡 Note

The variable names (length, width, area) are simple but descriptive, making it clear what each variable represents in the calculation.
