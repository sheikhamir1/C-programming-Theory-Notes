Real-Life Example

Here's a real-life example of using different data types, to calculate and output the total cost of a number of items:

1// Create variables of different data types
2int items = 50;
3float cost_per_item = 9.99;
4float total_cost = items * cost_per_item;
5char currency = '$';
6
7// Print variables
8printf("Number of items: %d\n", items);
9printf("Cost per item: %.2f %c\n", cost_per_item, currency);
10printf("Total cost = %.2f %c\n", total_cost, currency);

C Extended Types

More Data Types

Besides the basic types (int, float, double, char), C also gives you extended keywords (short, long, unsigned) to control how large the number is, or whether it can be negative:

Type Size* Range (commonly) Format Specifier
short int 2 bytes -32,768 to 32,767 %hd
unsigned int 2 or 4 bytes 0 to 65,535 (2 bytes)
0 to 4,294,967,295 (4 bytes) 		%u
long int 4 or 8 bytes -2,147,483,648 to 2,147,483,647 (4 bytes)
-9,223,372,036,854,775,808 to 9,223,372,036,854,775,807 (8 bytes) 		%ld
long long int 8 bytes -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807 %lld
unsigned long int 4 or 8 bytes 0 to 4,294,967,295 (4 bytes)
0 to 18,446,744,073,709,551,615 (8 bytes) 		%lu
unsigned long long int 8 bytes 0 to 18,446,744,073,709,551,615 %llu
long double 8, 12, or 16 bytes Implementation-dependent, but more precision than double %Lf
💡 Note

unsigned means the type can only store non-negative values (0 and up).

⚠️ System Dependency

The size of these types can differ between systems (for example, 2 or 4 bytes, or 4 or 8 bytes), depending on whether the computer is older or newer, 32-bit or 64-bit, and which compiler is used.

Extended Types Example

Here is an example of how you can create and print these extended types:

1int normalInt = 1000; // standard int
2double normalDouble = 3.14; // standard double
3
4short int small = -100; // smaller int
5unsigned int count = 25; // only positive int
6long int big = 1234567890; // larger int
7long long int veryBig = 9223372036854775807; // very large int
8unsigned long long int huge = 18446744073709551615U; // very large, only positive
9long double precise = 3.141592653589793238L; // extended precision
10
11printf("Normal int: %d\n", normalInt);
12printf("Normal double: %lf\n", normalDouble);
13printf("Small: %hd\n", small);
14printf("Count: %u\n", count);
15printf("Big: %ld\n", big);
16printf("Very Big: %lld\n", veryBig);
17printf("Huge: %llu\n", huge);
18printf("Precise: %Lf\n", precise);

Normal double: 3.140000
Small: -100
Count: 25

Very Big: 9223372036854775807
Huge: 18446744073709551615
Precise: 3.141593
💡 Usage Note

These extended types are mostly used when you need very specific control over memory usage or number ranges.

💡 Note

For everyday programming, int, float, double, and char are usually enough.
