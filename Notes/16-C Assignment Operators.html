Introduction to Assignment Operators 📚

Assignment operators are used to assign values to variables.

Basic Assignment =

In the example below, we use the assignment operator (=) to assign the value 10 to a variable called x:

int x = 10;

Addition Assignment +=

The addition assignment operator (+=) adds a value to a variable:

int x = 10;
x += 5;

Most assignment operators are just shorter ways of writing code. For example, x += 5 is the same as x = x + 5, but shorter and often easier to read.

Real-Life Example: Tracking Savings 💰

Assignment operators can also be used in real-life scenarios. For example, you can use the += operator to keep track of savings when you add money to an account:

int savings = 100;
savings += 50; // add 50 to savings

printf("Total savings: %d\n", savings);
Output:
Total savings: 150

Explanation 📖

In this example:

  • We start with an initial savings of 100
  • We use the += operator to add 50 to the existing savings
  • The final savings amount is 150

C Comparison Operators ⚖️

Comparison operators are used to compare two values (or variables). This is important in programming, because it helps us to find answers and make decisions.

Boolean Values 🔍

The return value of a comparison is either 1 or 0, which means true (1) or false (0). These values are known as Boolean values, and you will learn more about them in the Booleans and If..Else chapter.

Example 💻

In the following example, we use the greater than operator (>) to find out if 5 is greater than 3:

int x = 5;
int y = 3;
printf("%d", x > y); // returns 1 (true) because 5 is greater than 3
Output: 1

Real-Life Examples 🌍

Comparison operators are often used in real-world conditions, such as checking if a person is old enough to vote:

Voting Age Check 🗳️

int age = 18;

printf("%d\n", age >= 18); // 1 (true), old enough to vote
printf("%d\n", age < 18); // 0 (false), not old enough
Output:
1
0

Password Length Check 🔐

Another common use is checking if a password is long enough:

int passwordLength = 5;

printf("%d\n", passwordLength >= 8); // 0 (false), too short
printf("%d\n", passwordLength < 8); // 1 (true), needs more characters
Output:
0
1

C Logical Operators 🧠

As with comparison operators, you can also test for true or false values with logical operators.

Combining Conditions 🔗

Logical operators are used to determine the logic between variables or values, by combining multiple conditions:

Operator Name Example Description
&& AND x < 5 && x < 10 Returns 1 if both statements are true
|| OR x < 5 || x < 4 Returns 1 if one of the statements is true
! NOT !(x < 5 && x < 10) Reverse the result, returns 0 if the result is 1
8/13

Real-Life Example: Login Check 🔑

The example below shows how logical operators can be used in a real situation, e.g. when checking login status and access rights:

bool isLoggedIn = true;
bool isAdmin = false;

printf("Regular user: %s\n", (isLoggedIn && !isAdmin) ? "true" : "false");
printf("Has access: %s\n", (isLoggedIn || isAdmin) ? "true" : "false");
printf("Not logged in: %s\n", (!isLoggedIn) ? "true" : "false");
Result:
Regular user: true
Has access: true
Not logged in: false

Explanation 📖

  • isLoggedIn && !isAdmin returns true because the user is logged in and is not an admin
  • isLoggedIn || isAdmin returns true because the user is logged in (even though not an admin)
  • !isLoggedIn returns false because the user is logged in

C Operator Precedence 📊

When a calculation contains more than one operator, C follows order of operations rules to decide which part to calculate first.

Example 💻

For example, multiplication happens before addition:

int result1 = 2 + 3 * 4; // 2 + 12 = 14
int result2 = (2 + 3) * 4; // 5 * 4 = 20

printf("%d\n", result1);
printf("%d\n", result2);
Output:
14
20

Why Does This Happen? ❓

In 2 + 3 * 4, the multiplication is done first, so the answer is 14.

If you want the addition to happen first, you must use parentheses: (2 + 3) * 4, which gives 20.

💡 Tip

Always use parentheses ( ) if you want to make sure the calculation is done in the order you expect. It also makes your code easier to read.

Another Example 🔢

Subtraction and addition are done from left to right, unless you add parentheses:

int result1 = 10 - 2 + 5; // (10 - 2) + 5 = 13
int result2 = 10 - (2 + 5); // 10 - 7 = 3

printf("%d\n", result1);
printf("%d\n", result2);
Output:
13
3

Explanation 📖

  • In the first example, 10 - 2 + 5, the subtraction happens first (10 - 2 = 8), then the addition (8 + 5 = 13)
  • In the second example, 10 - (2 + 5), the parentheses force the addition to happen first (2 + 5 = 7), then the subtraction (10 - 7 = 3)

Remember: Parentheses always come first. Use them to control the order of your calculations. ✅
