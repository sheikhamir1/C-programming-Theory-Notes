What is Pointer Arithmetic? 🤔

Pointer arithmetic means changing the value of a pointer to make it point to a different element in memory.

Array elements are stored next to each other in memory. So if a pointer points to one element, adding 1 moves it to the next one:

myNumbers[0]
→
myNumbers[1]
→
myNumbers[2]
💡 Key Concept

Pointer arithmetic allows you to navigate through memory locations by adding or subtracting values from a pointer.

2/9

Basic Pointer Operations 🔧

Example

int myNumbers[4] = {25, 50, 75, 100};
int *p = myNumbers; // points to myNumbers[0]

printf("%d\n", *p); // 25
printf("%d\n", *(p + 1)); // 50
printf("%d\n", *(p + 2)); // 75
printf("%d\n", *(p + 3)); // 100

Output:

25

50

75

100

📌 Remember

The pointer p starts at the first element of the array, and adding an offset (like p+1) moves it to subsequent elements.

3/9

Increment and Decrement ⬆️⬇️

You can move a pointer with ++ and -- (and with += / -=):

int myNumbers[3] = {10, 20, 30};
int *p = myNumbers; // myNumbers[0]

printf("%d\n", *p); // 10
p++; // move to myNumbers[1]
printf("%d\n", *p); // 20
p--; // back to myNumbers[0]
printf("%d\n", *p); // 10

p += 2; // jump to myNumbers[2]
printf("%d\n", *p); // 30
🎯

Key Point

You can move a pointer just like a counter: each time you use p++ or p--, it moves to the next or previous element in the array.

4/9

Pointer Subtraction (Distance) 📏

You can subtract two pointers that point to elements in the same array to find out how many elements are between them:

int myNumbers[5] = {10, 20, 30, 40, 50};
int *start = &myNumbers[1]; // points to 20
int *end = &myNumbers[4]; // points to 50

printf("%ld\n", end - start); // 3 elements apart

start
30
40
50
end
⚠️ Important Note

Pointer subtraction only works when both pointers point into the same array. The result is measured in elements, not bytes.

5/9

Pointer Arithmetic Depends on Type 🔄

Not all pointers move the same way. When you add 1 to a pointer, it moves forward by the size of the thing it points to - not just by 1 byte.

🔢

int* Pointer

Moves by the size of an integer (usually 4 bytes)

🔤

char* Pointer

Moves by the size of a character (1 byte)

Example

int myNumbers[2] = {1, 2};
char letters[] = "Hi"; // 'H', 'i', '\0'

int *pi = myNumbers; // int pointer
char *pc = letters; // char pointer

printf("%p\n", (void*)pi);
printf("%p\n", (void*)(pi + 1)); // moves by sizeof(int) (4 bytes)
printf("%p\n", (void*)(pi + 2)); // moves by sizeof(int) (4 bytes)

printf("%p\n", (void*)pc);
printf("%p\n", (void*)(pc + 1)); // moves by 1 byte
6/9

Looping with Pointers 🔄

Let's look at how to loop through an array by moving the pointer itself inside the loop. Each time the pointer is increased (p++), it moves to the next element in memory:

int myNumbers[4] = {25, 50, 75, 100};
int *p = myNumbers; // start of array

for (int i = 0; i < 4; i++) {
  printf("%d\n", *p);
  p++; // move to next element
}
Initial state:
p → myNumbers[0]
After 1st loop:
p → myNumbers[1]
After 2nd loop:
p → myNumbers[2]
After 3rd loop:
p → myNumbers[3]
💡 Pro Tip

This way of looping is common when working directly with memory, since the pointer itself moves through the array instead of using an index number.

Common Mistakes to Avoid ⚠️

🔧
Wrong Type
Remember that pointer movement depends on its type. An int* moves in 4-byte steps, but a char* moves 1 byte at a time.
🚫
Uninitialized Pointers
Always make sure a pointer is pointing to something real before you use it. Using a pointer that doesn't point anywhere can crash your program.
📏
Going Out of Bounds
Never move a pointer past the end of an array or before it starts. The only safe "outside" position is one step past the end, and that's only for comparing pointers.

⚠️ Be Careful!

Pointers must be handled with care, since it is possible to damage data stored in other memory addresses.
