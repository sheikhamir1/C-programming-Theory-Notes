Structures 📊

Structures (also called structs) are a way to group several related variables into one place.

Each variable in a structure is known as a member of the structure.

Unlike an array, a structure can contain many different data types (int, float, char, etc.).

Structure Definition

struct MyStructure {
  int myNum;
  char myLetter;
};
→

Structure Members

Create a Structure 🏗️

You can create a structure by using the struct keyword and declare each of its members inside curly braces:

struct MyStructure {
  // Structure declaration
  int myNum;
  char myLetter;
}; // End of structure with a semicolon
💡 Syntax

Structure members are declared inside the curly braces, and each member is followed by its type and name.

3/9

Access Structure Members 🔑

To access members of a structure, you must create a variable of it.

Use the struct keyword inside main() method, followed by the name of the structure and then a name for the structure variable:

struct MyStructure {
  int myNum;
  char myLetter;
};

int main() {
  // Create a structure variable of MyStructure called s1
  struct MyStructure s1;

  // Assign values to members of s1
  s1.myNum = 13;
  s1.myLetter = 'B';

  // Print values
  printf("My number: %d\n", s1.myNum);
  printf("My letter: %c\n", s1.myLetter);

  return 0;
}
}

Output:

My number: 13

My letter: B

Arrays of Structures 📊

Just like with regular variables, you can create arrays of structures. This is useful when you need to store multiple records of the same type.

struct MyStructure {
  int myNum;
  char myLetter;
};

int main() {
  // Create an array of 3 MyStructure variables
  struct MyStructure arr[3];

  // Assign values to array elements
  arr[0].myNum = 10;
  arr[1].myNum = 20;
  arr[2].myNum = 30;

  // Print values from array
  for (int i = 0; i < 3; i++) {
    printf("My number: %d\n", arr[i].myNum);
    printf("My letter: %c\n", arr[i].myLetter);
  }
  return 0;
}
}

Output:

My number: 10

My letter: J

My number: 20

My number: 30

Strings in Structures 🔤

Remember that strings in C are actually an array of characters, and unfortunately, you can't assign a value to an array like this:

struct myStructure {
  int myNum;
  char myLetter;
  char myString[30];
};

int main() {
  struct myStructure s1;
  // Trying to assign a value to string
  s1.myString = "Some text";
  printf("My string: %s", s1.myString);
  return 0;
}
}

Output:

My string: Some text

⚠️ Problem

An error will occur:

prog.c:12:15: error: assignment to expression with array type

Copying Structures 📋

You can also assign one structure to another:

struct myStructure {
  int myNum;
  char myLetter;
};

int main() {
  struct myStructure s1, s2;
  // Assign values to s1
  s1.myNum = 13;
  s1.myLetter = 'B';
  // Copy s1 to s2
  s2 = s1;
  // Change s2 values
  s2.myNum = 20;
  s2.myLetter = 'C';
  // Print values
  printf("s1: %d %c\n", s1.myNum, s1.myLetter);
  printf("s2: %d %c\n", s2.myNum, s2.myLetter);
  return 0;
}
}

Output:

s1: 13 B

s2: 20 C

Modifying Structure Values ✏️

If you want to change/modify a value, you can use the dot syntax (.).

And to modify a string value, you can use the strcpy() function, like this:

struct myStructure {
  int myNum;
  char myLetter;
  char myString[30];
};

int main() {
  struct myStructure s1;
  // Modify values
  s1.myNum = 30;
  s1.myLetter = 'B';
  // Change s2 values
  s2.myNum = 20;
  s2.myLetter = 'C';
  // Modify string value
  strcpy(s2.myString, "Something else");
  // Print values
  printf("s1: %d %c\n", s1.myNum, s1.myLetter);
  printf("s2: %d %c\n", s2.myNum, s2.myLetter);
  return 0;
}
}

Real-Life Example with Cars 🚗

Imagine you have to write a program to store different information about Cars, such as brand, model, and year. What's great about structures is that you can create a single "Car template" and use it for every car you make.

See below for a real life example:

struct Car {
  char brand[30];
  char model[30];
  int year;
};

int main() {
  struct Car car1 = {"BMW", "X5", 1999};
  struct Car car2 = {"Ford", "Mustang", 1969};
  struct Car car3 = {"Toyota", "Corolla", 2011};

  // Create structure variables
  struct Car car1, car2, car3;

  // Assign values
  car1 = {"BMW", "X5", 1999};
  car2 = {"Ford", "Mustang", 1969};
  car3 = {"Toyota", "Corolla", 2011};

  // Print car information
  printf("Brand: %s, Model: %s, Year: %d\n", car1.brand, car1.model, car1.year);
  printf("Brand: %s, Model: %s, Year: %d\n", car2.brand, car2.model, car2.year);
  printf("Brand: %s, Model: %s, Year: %d\n", car3.brand, car3.model, car3.year);
  return 0;
}

Output:

Brand: BMW, Model: X5, Year: 1999

Brand: Ford, Model: Mustang, Year: 1969

Brand: Toyota, Model: Corolla, Year: 2011

Summary 📝

Key Takeaways

  • Structures group related variables into one place
  • Each variable in a structure is known as a member
  • Structures can contain different data types
  • Use the struct keyword to define a structure
  • Access members using the dot operator (.)
  • Arrays of structures are useful for storing multiple records
  • Use strcpy() to copy strings to structure members
  • Modify structure values using the dot operator
