While Loop 🔄

The while loop repeats a block of code as long as a specified condition is true:

Syntax 📝

while (condition) {
  // code block to be executed
}

Basic Example 💻

In the example below, code in the loop will run, over and over again, as long as a variable (i) is less than 5:

int i = 0;

while (i < 5) {
  printf("%d\n", i);
  i++;
}
Output:
0
1
2
3
4
💡 Important Note

Do not forget to increase the variable used in the condition (i++), otherwise the loop will never end!

Why Use 'i' as Variable Name? ❓

Do you wonder why we use the letter 'i' as a variable name? It's a counter variable and a common choice in simple loops because it's short, traditional, and stands for 'index' or 'iterator'.

3/9

Countdown Example ⏱️

You can also use a while loop to count down. This example counts from 3 to 1, and then prints "Happy New Year!!" at the end:

int countdown = 3;

while (countdown > 0) {
  printf("%d\n", countdown);
  countdown--;
}
printf("Happy New Year!!\n");
Output:
3
2
1
Happy New Year!!

Explanation 📖

  • We initialize a countdown variable with value 3
  • The while loop continues as long as countdown > 0
  • Each iteration prints the current value and then decrements it
  • After the loop finishes, we print "Happy New Year!!"
4/9

While Loop With False Condition ❌

In previous examples, the condition was true at the start, so the loop ran one or more times. But if the condition is false at the beginning, the code inside the loop will never run:

int i = 10;

while (i < 5) {
  printf("This will never be printed\n");
  i++;
}
Output: (No output)

Explanation 📖

In this example, the variable i starts with value 10, which is not less than 5. Since the condition (i < 5) is false from the beginning, the code inside the while loop never executes.

💡 Next Up

A while loop may never run if the condition is false from the start. In the next chapter, you will learn about the do while loop, which always runs the code at least once before checking the condition.

The Do/While Loop 🔄➡️

The do/while loop is a variant of the while loop. This loop will execute the code block once, before checking if the condition is true, then it will repeat the loop as long as the condition is true.

Syntax 📝

do {
  // code block to be executed
}
while (condition);

Basic Example 💻

The example below uses a do/while loop. The loop will always be executed at least once, even if the condition is false, because the code block is executed before the condition is tested:

int i = 0;

do {
  printf("%d\n", i);
  i++;
}
while (i < 5);
Output:
0
1
2
3
4
💡 Important Note

Do not forget to increase the variable used in the condition, otherwise the loop will never end!

6/9

Condition is False from Start ❌

In the previous example, the condition i < 5 was true at the beginning, so the loop executed multiple times. But what if the condition is false right from the start?

Example 💻

In the example below, the variable i starts at 10, so the condition i < 5 is false immediately - yet the do/while loop still runs once:

int i = 10;

do {
  printf("i is %d\n", i);
  i++;
} while (i < 5);
Output:
i is 10

Explanation 📖

Even if the condition is false from the start, the code block will still execute one time because the do/while loop executes the code before checking the condition.

💡 Key Difference

The do/while loop always runs at least once, even if the condition is already false. This is different from a regular while loop, which would skip the loop entirely if the condition is false at the start.

Practical Use 🔧

This behavior makes do/while useful when you want to ensure something happens at least once, like showing a message or asking for user input.

7/9

Practical Example: User Input 👤

This example keeps asking the user to enter a positive number. The loop stops when the user enters 0 or a negative number:

int number;

do {
  printf("Enter a positive number: ");
  scanf("%d", &number);
} while (number > 0);

Explanation 📖

  • The do/while loop ensures the prompt appears at least once
  • After the user enters a number, the condition checks if it's greater than 0
  • If it is, the loop repeats and asks for another number
  • If the user enters 0 or a negative number, the loop ends

Note: You will learn more about the scanf() function and user input in a later chapter.
