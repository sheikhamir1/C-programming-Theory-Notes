Switch Statement 🔄

Instead of writing many if..else statements, you can use switch statement.

Purpose 🎯

The switch statement selects one of many code blocks to be executed:

Advantages ✅

  • Cleaner and more readable code than multiple if-else statements
  • More efficient for comparing a variable against multiple constants
  • Easier to maintain and modify
🔄

Switch

Selects one of many code blocks

📦

Cases

Different options to match

🛑

Break

Exits the switch block

2/8

Syntax 📝

The basic syntax of a switch statement in C:

switch (expression) {
  case x:
    // code block
    break;
  case y:
    // code block
    break;
  default:
    // code block
}

Key Components 🔧

  • switch - The keyword that starts the switch statement
  • expression - The value to be compared against each case
  • case - A specific value to match against the expression
  • break - Exits the switch block after a match is found
  • default - Optional code block to execute if no case matches
3/8

How Switch Works ⚙️

This is how a switch statement works:

1️⃣
Evaluation
The switch expression is evaluated once
2️⃣
Comparison
The value of expression is compared with values of each case
3️⃣
Execution
If there is a match, the associated block of code is executed
4️⃣
Breaking Out
The break statement breaks out of the switch block and stops execution
5️⃣
Default Case
The default statement is optional, and specifies some code to run if there is no case match
4/8

Example 💻

The example below uses weekday number to calculate weekday name:

int day = 4;

switch (day) {
  case 1:
    printf("Monday");
    break;
  case 2:
    printf("Tuesday");
    break;
  case 3:
    printf("Wednesday");
    break;
  case 4:
    printf("Thursday");
    break;
  case 5:
    printf("Friday");
    break;
  case 6:
    printf("Saturday");
    break;
  case 7:
    printf("Sunday");
    break;
}
Output: "Thursday" (day 4)

Explanation 📖

In this example, the value of day (4) is compared against each case. When it matches case 4, the code for that case is executed, printing "Thursday". The break statement then exits the switch block.

The break Keyword 🛑

When C reaches a break keyword, it breaks out of the switch block.

Purpose of break 🎯

This will stop the execution of more code and case testing inside the block.

When a match is found, and the job is done, it's time for a break. There is no need for more testing.

Performance Benefit ⚡

A break can save a lot of execution time because it "ignores" the execution of all the rest of the code in the switch block.

💡 Important Note

Forgetting to include a break statement can lead to "fall-through" behavior, where code from subsequent cases is also executed. This is sometimes intentional, but often it's a bug.

switch (day) {
  case 1:
    printf("Monday");
    break; // Exit switch after printing Monday
  case 2:
    printf("Tuesday");
    break; // Exit switch after printing Tuesday
  // ... more cases
}

The default Keyword 🔧

The default keyword specifies some code to run if there is no case match:

int day = 4;

switch (day) {
  case 6:
    printf("Today is Saturday");
    break;
  case 7:
    printf("Today is Sunday");
    break;
  default:
    printf("Looking forward to the Weekend");
}
Output: "Looking forward to the Weekend"

Explanation 📖

In this example, the value of day (4) doesn't match case 6 or case 7, so the default case is executed, printing "Looking forward to the Weekend".

💡 Important Note

The default keyword must be used as the last statement in the switch, and it does not need a break statement.

Key Points 🔑

  • Switch statements are a cleaner alternative to multiple if-else statements
  • The switch expression is evaluated once and compared with each case
  • Use break to exit the switch block after a match
  • The default case handles values that don't match any case
  • default should be the last case in the switch statement

Switch statements make your code more organized and readable when dealing with multiple conditions! ✅
