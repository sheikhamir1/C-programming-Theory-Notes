C Storage Classes 💾

What are Storage Classes?

Storage classes define the lifetime, visibility, and memory location of variables.

There are four main storage class specifiers in C:

  • auto
  • static
  • register
  • extern
💡
Scope vs Storage Classes

Scope defines where a variable can be used, and storage classes define how long it lasts and where it's stored. This chapter continues from the C Scope chapter.

2/18

auto Storage Class 🔄

🔄 Local Variables with Automatic Storage

The auto keyword is used for local variables. It is default for variables declared inside functions, so it's rarely used explicitly.

int main() {
  auto int x = 50; // Same as just: int x = 50;
  printf("%d\n", x);
  return 0;
}
💡
Key Points

auto variables are created when the function is called and destroyed when the function exits. They have local scope and are stored on the stack.

3/18

static Storage Class 📌

📌 Persistent Variables

The static keyword changes how a variable or function behaves in terms of lifetime and visibility:

  • Static local variables keep their value between function calls.
  • Static global variables/functions are not visible outside their file.
void count() {
  static int myNum = 0; // Keeps its value between calls
  myNum++;
  printf("num = %d\n", myNum);
}

int main() {
  count();
  count();
  count();
  return 0;
}
Result:
num = 1
num = 2
num = 3
💡
Try It Yourself

Try to remove the static keyword from the example to see the difference.

4/18

register Storage Class ⚡

⚡ Fast Access Variables

The register keyword suggests that the variable should be stored in a CPU register (for faster access).

You cannot take the address of a register variable using &.

⚠️
Modern Compilers

The register keyword is mostly obsolete - modern compilers automatically choose the best variables to keep in registers, so you usually don't need to use it.

int main() {
  register int counter = 0;
  printf("Counter: %d\n", counter);
  return 0;
}
5/18

extern Storage Class 🔗

🔗 Variables Across Files

The extern keyword tells the compiler that a variable or function is defined in another file.

It is commonly used when working with multiple source files.

File 1: main.c
#include <stdio.h>

extern int shared; // Declared here, defined in another file

int main() {
  printf("shared = %d\n", shared);
  return 0;
}
File 2: data.c
int shared = 50; // Definition of the variable
Compile both files together:
gcc main.c data.c -o program

Key Takeaway

Storage classes determine where variables are stored, their default values, scope, and lifetime. Choosing the right storage class is important for efficient memory usage and program behavior.

C Bitwise Operators 🔢

Working with Bits

Note: This is a more advanced topic in C. If you are new to programming, don't worry if it feels tricky at first - bitwise operators are mainly used in special cases like system programming, hardware control, or performance optimizations.

In C, bitwise operators let you work directly with the bits (the 1s and 0s) that make up numbers in binary form.

💡
Binary Representation

Every integer in a computer is stored in binary, which means it is represented using bits (binary digits) that are either 0 or 1. Bitwise operators allow you to compare, combine, shift, or flip these bits.

⚠️
Important Note

Bitwise operations only work on integer types (such as int, char, or long).

8/18

List of Bitwise Operators 🔧

Operator Name Description
& AND Sets each bit to 1 if both bits are 1
| OR Sets each bit to 1 if at least one of the bits is 1
^ XOR Sets each bit to 1 if only one of the bits is 1
~ NOT Inverts all the bits
<< Left Shift Shifts bits to the left (multiplies by powers of 2)
>> Right Shift Shifts bits to the right (divides by powers of 2)

Bitwise AND (&) 🔗

🔗 Bitwise AND Operation

The & operator compares each bit and returns 1 only if both bits are 1.

int a = 6; // 0110
int b = 3; // 0011

int result = a & b;
printf("Result: %d\n", result); // 2 (0010)

Bitwise OR (|) and XOR (^) 🔀

🔀 Bitwise OR Operation

The | operator sets a bit to 1 if either bit is 1.

int a = 6; // 0110
int b = 3; // 0011

int result = a | b;
printf("Result: %d\n", result); // 7 (0111)
🔀 Bitwise XOR Operation

The ^ operator returns 1 only when the bits are different.

int a = 6; // 0110
int b = 3; // 0011

int result = a ^ b;
printf("Result: %d\n", result); // 5 (0101)
13/18

Bitwise NOT (~) and Shifts 🔄

🔄 Bitwise NOT Operation

The ~ operator inverts each bit (0 becomes 1 and 1 becomes 0).

int a = 5; // 00000101

int result = ~a;
printf("Result: %d\n", result); // -6 on most systems

Note: The result of ~ depends on how negative numbers are stored (usually two's complement). For example, 5 (00000101) becomes 11111010, which is interpreted as -6.

⬅️➡️ Shift Operations

The << operator shifts bits to the left and fills in 0s on the right. This is the same as multiplying by powers of 2.

The >> operator shifts bits to the right. This is the same as dividing by powers of 2.

int a = 3; // 00000011
int result = a << 2; // 12 (3 * 2^2)

int b = 12; // 00001100
int result2 = b >> 2; // 3 (12 / 2^2)

Real-Life Example: Flags and Permissions 🚩

🚩 Using Bitwise Operators for Flags

Bitwise operators are often used to store multiple options in a single integer, using flags.

#define READ 1 // 0001
#define WRITE 2 // 0010
#define EXEC 4 // 0100

int permissions = READ | WRITE; // user can read and write

if (permissions & READ) {
  printf("Read allowed\n");
}
if (permissions & WRITE) {
  printf("Write allowed\n");
}
if (permissions & EXEC) {
  printf("Execute allowed\n");
}

In this example, the user has both READ and WRITE permissions, but not EXEC.

Bitwise Operators Summary 📝

Key Takeaways

  • Bitwise operators work on individual bits of integers
  • &: AND - both bits must be 1
  • |: OR - either bit can be 1
  • ^: XOR - only one bit is 1
  • ~: NOT - flips all bits
  • <<: Left shift - multiplies by powers of 2
  • >>: Right shift - divides by powers of 2
💡
Practical Applications

Bitwise operations are useful for optimization, low-level hardware access, flags, and masks.
