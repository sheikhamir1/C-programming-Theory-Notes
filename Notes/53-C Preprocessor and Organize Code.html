Preprocessor and Macros 🔧

What is the Preprocessor?

In C, the preprocessor runs before the actual compilation begins. It handles things like including files and defining macros.

Preprocessor commands begin with a # symbol and are called directives.

Key Point

The preprocessor modifies your source code before compilation, but these changes are not visible in your original source files.

#include - Include Header Files 📁

📁 Adding Libraries and Header Files

You have already seen the #include directive many times - It tells the compiler to include a file.

It is used to add libraries or custom header files:

#include <stdio.h>
#include "myfile.h"

Use angle brackets < > for standard libraries and double quotes " " for your own files.

💡
Tip

The most commonly used libraries can be found in our C Reference Documentation.

#define - Create a Macro 🏷️

🏷️ Defining Constants and Code Shortcuts

A macro is a name that represents a value (like PI), or a piece of code, defined using the #define directive.

In the example below, PI is replaced with 3.14 before the program is compiled.

This means that every time PI appears in the code, it will be replaced with 3.14:

#define PI 3.14

int main() {
  printf("Value of PI: %.2f\n", PI);
  return 0;
}

Before Preprocessing

printf("Value: %.2f\n", PI);

→

After Preprocessing

printf("Value: %.2f\n", 3.14);

4/14

Macros with Parameters 🔧

🔧 Function-like Macros

Macros can also take parameters, like a function:

#define SQUARE(x) ((x) * (x))

int main() {
  printf("Square of 4: %d\n", SQUARE(4));
  return 0;
}

Macros with parameters work like shortcuts, but be careful with parentheses to avoid mistakes.

⚠️
Parentheses are Important

Notice the extra parentheses around x in the SQUARE macro. This prevents issues with operator precedence when the macro is expanded.

Before Preprocessing

SQUARE(4)

→

After Preprocessing

((4) * (4))

#ifdef and #ifndef - Conditional Compilation 🔀

🔀 Including Code Conditionally

The #ifdef and #ifndef directives let you include or skip parts of the code depending on whether a macro is defined.

This is called conditional compilation, and it's useful for debugging or creating different versions of a program.

#define DEBUG

int main() {
  #ifdef DEBUG
    printf("Debug mode is ON\n");
  #endif
  return 0;
}

If DEBUG is defined, the message will be printed. If it's not defined, that part of the code is skipped.

Organize Your Code - Modular Programming 🏗️

What is Modular Programming?

In C programming, modular programming means splitting your code into smaller, reusable parts.

This makes your code easier to read, maintain, and debug.

📁
File Organization

The most common way to organize C programs is by using separate .c files and .h header files.

Even though this approach is not required for small beginner programs, it is very useful for larger projects or more experienced programmers who want to keep their code clean and well-structured.

9/14

calc.h File 📄

📄 1. calc.h - Header File

Start by creating a header file named calc.h to declare the functions:

#ifndef CALC_H
#define CALC_H

int add(int x, int y);
int subtract(int x, int y);

#endif
💡
Include Guard

The #ifndef, #define, and #endif lines are called an include guard. They prevent the file from being included more than once by mistake, which can cause errors during compilation.

📝
Function Declarations

This file itself contains declarations of two functions: add() and subtract().

10/14

calc.c File 💻

💻 2. calc.c - Source File

Next, write the function definitions inside your calc.c file:

#include "calc.h"

int add(int x, int y) {
  return x + y;
}

int subtract(int x, int y) {
  return x - y;
}

This file defines the functions declared in calc.h.

11/14

main.c File 🚀

🚀 3. main.c - Main Program

Finally, write the main program in main.c and include the header file to use the calculator functions:

#include <stdio.h>
#include "calc.h"

int main() {
  printf("5 + 5 = %d\n", add(5, 5));
  printf("6 - 4 = %d\n", subtract(6, 4));
  return 0;
}
Result:
5 + 5 = 10
6 - 4 = 2

How to Compile Multiple Files 🔨

🔨 Building from Multiple Source Files

When your program is split across multiple files, you need to compile them together. For example:

gcc main.c calc.c -o program

This tells the compiler to build one executable named program from both main.c and calc.c.

+

calc.c

→

💡
Build Process

The compiler automatically links the function calls in main.c with their definitions in calc.c, thanks to the declarations in calc.h.

Summary 📝

Key Takeaways

  • The preprocessor runs before compilation and processes directives that start with #
  • #include adds header files to your program
  • #define creates macros that represent values or code
  • #ifdef and #ifndef allow conditional compilation based on whether a macro is defined
  • Modular programming organizes code into separate files for better maintainability
  • Header files (.h) contain declarations, while source files (.c) contain definitions
  • Include guards (#ifndef/#define/#endif) prevent header files from being included multiple times
  • Multiple source files are compiled together using commands like "gcc main.c calc.c -o program"
