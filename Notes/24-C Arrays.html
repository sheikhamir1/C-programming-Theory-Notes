C Arrays 📚

Storing multiple values in a single variable 📦

Arrays are used to store multiple values in a single variable, instead of declaring separate variables for each value.

1/13

Arrays 📚

To create an array, define the data type (like int) and specify the name of the array followed by square brackets [].

Creating an Array 📝

To insert values to it, use a comma-separated list inside curly braces, and make sure all values are of the same data type:

int myNumbers[] = {25, 50, 75, 100};
💡 Array Structure

We have now created a variable that holds an array of four integers.

2/13

Accessing Elements of an Array 🔍

To access an array element, refer to its index number.

💡 Indexing

Array indexes start with 0: [0] is the first element. [1] is the second element, etc.

Example 💻

This statement accesses the value of the first element [0] in myNumbers:

int myNumbers[] = {25, 50, 75, 100};

printf("%d", myNumbers[0]);

// Outputs 25
Output: 25
3/13

Change an Array Element ✏️

To change the value of a specific element, refer to the index number:

Example 💻

int myNumbers[] = {25, 50, 75, 100};

myNumbers[0] = 33;

printf("%d", myNumbers[0]);

// Now outputs 33 instead of 25
Output: 33
4/13

Set Array Size 📏�️

Another common way to create arrays is to specify the size of the array, and add elements later:

Example 💻

// Declare an array of four integers:
int myNumbers[4];

// Add elements
myNumbers[0] = 25;
myNumbers[1] = 50;
myNumbers[2] = 75;
myNumbers[3] = 100;
💡 Memory Management

Using this method, you should know the number of array elements in advance, in order for the program to store enough memory.

⚠️ Important Note

You are not able to change the size of an array after creation.

5/13

Avoid Mixing Data Types ⚠️

It is important to note that all elements in an array must be of the same data type.

Example 💻

This means you cannot mix different types of values, like integers and floating point numbers, in the same array:

int myArray[] = {25, 50, 75, 3.15, 5.99};
💡 Type Conversion

In the example above, the values 3.15 and 5.99 will be truncated to 3 and 5. In some cases it might also result in an error, so it is important to always make sure that the elements in an array are of the same type.

6/13

Get Array Size 📏�️

To get the size of an array, you can use the sizeof operator:

Example 💻

int myNumbers[] = {10, 25, 50, 75, 100};

printf("%zu", sizeof(myNumbers)); // Prints 20
Output: 20
❓ Why 20 instead of 5?

You learned from the Data Types chapter that an int type is usually 4 bytes, so from the example above, 4 x 5 (4 bytes x 5 elements) = 20 bytes.

Memory Management 💾

Knowing the memory size of an array is great when you are working with larger programs that require good memory management.

7/13

Get the Number of Elements 🔢

If you want to find out how many elements an array has, you can use this formula, which divides the total size of the array by the size of one element:

Example 💻

int myNumbers[] = {10, 25, 50, 75, 100};

int length = sizeof(myNumbers) / sizeof(myNumbers[0]);

printf("%d", length); // Prints 5
Output: 5

Universal Formula 🔄

The sizeof formula works for arrays of any type and any size:

double myValues[] = {1.1, 2.2, 3.3};

int length = sizeof(myValues) / sizeof(myValues[0]);

printf("%d", length); // Prints 3
Output: 3
💡 Flexible Loops

In the next chapter, you will see how to use this formula to make loops that automatically adapt to the array size.

8/13

Loop Through an Array 🔄

You can use a for loop to go through the elements of an array by writing the size of the array in the loop condition (in this example the array has 4 elements, so we use i < 4). However, this is not ideal, since it will only work for arrays of a specified size.

Basic Example 💻

int myNumbers[] = {25, 50, 75, 100};

int i;

for (i = 0; i < 4; i++) {
  printf("%d\n", myNumbers[i]);
}
Output:
25
50
75
100

Making Better Loops ⚡

In the previous chapter, you learned how to calculate the number of elements in an array using the sizeof formula. Now we can use that to write loops that work for arrays of any size. This is more flexible and sustainable:

int myNumbers[] = {25, 50, 75, 100};

int length = sizeof(myNumbers) / sizeof(myNumbers[0]);

int i;

for (i = 0; i < length; i++) {
  printf("%d\n", myNumbers[i]);
}
💡 Best Practice

Summary: Always use the sizeof formula when looping through arrays. It makes your loops adapt to the array size automatically.

9/13

Real-Life Examples 🌍

To demonstrate practical examples of using arrays, let's create programs that work with collections of data:

Calculate Average Age 👥

This example creates a program that calculates the average of different ages:

// An array storing different ages
int ages[] = {20, 22, 18, 35, 48, 26, 87, 70};

float avg, sum = 0;
int i;

// Get the length of the array
int length = sizeof(ages) / sizeof(ages[0]);

// Loop through the elements of the array
for (i = 0; i < length; i++) {
  sum += ages[i];
}

// Calculate the average by dividing the sum by the length
avg = sum / length;

// Print the average
printf("The average age is: %.2f", avg);
Output: The average age is: 39.57

Find Lowest Age 🔍

This example creates a program that finds the lowest age among different ages:

// An array storing different ages
int ages[] = {20, 22, 18, 35, 48, 26, 87, 70};

int i;

// Get the length of the array
int length = sizeof(ages) / sizeof(ages[0]);

// Create a variable and assign the first array element of ages to it
int lowestAge = ages[0];

// Loop through the elements of the ages array to find the lowest age
for (i = 0; i < length; i++) {
  if (lowestAge > ages[i]) {
    lowestAge = ages[i];
  }
}
Output: 18 (the lowest age in the array)

Filtering Numbers 🔍

In this example, we go through a list of numbers. We skip negative values, but stop the loop completely if we find a zero:

int myNumbers[] = {3, -1, 7, 0, 9};

int length = sizeof(myNumbers) / sizeof(myNumbers[0]);

int i;

for (i = 0; i < length; i++) {
  if (myNumbers[i] < 0) {
    continue; // skip negative numbers
  }
  if (myNumbers[i] == 0) {
    break; // stop loop when zero is found
  }
  printf("%d\n", myNumbers[i]);
}
Output:
3
7
💡 Key Concepts
  • The array contains numbers 3, -1, 7, 0, and 9
  • The loop processes each element in the array
  • When it encounters -1, the continue statement skips it
  • When it encounters 0, the break statement stops the loop completely
  • Only 3 and 7 are printed before the loop stops

Multidimensional Arrays 📊

In the previous chapter, you learned about arrays, which is also known as single dimension arrays. These are great, and something you will use a lot while programming in C. However, if you want to store data as a tabular form, like a table with rows and columns, you need to get familiar with multidimensional arrays.

Array Dimensions 📐

A multidimensional array is basically an array of arrays.

Arrays can have any number of dimensions. In this chapter, we will introduce the most common; two-dimensional arrays (2D).

11/13

Two-Dimensional Arrays 📊

A 2D array is also known as a matrix (a table of rows and columns).

Creating a 2D Array 📝

To create a 2D array of integers, take a look at the following example:

int matrix[2][3] = { {1, 4, 2}, {3, 6, 8} };

12/13

Accessing Elements of a 2D Array 🔍

To access an element of a two-dimensional array, you must specify the index number of both the row and the column.

💡 Indexing

Remember that: Array indexes start with 0: [0] is the first element. [1] is the second element, etc.

Example 💻

This statement accesses the value of the element in the first row (0) and third column (2) of the matrix array:

int matrix[2][3] = { {1, 4, 2}, {3, 6, 8} };

printf("%d", matrix[0][2]); // Outputs 2
Output: 2

Change Elements ✏️

To change the value of an element, refer to the index number of the element in each of the dimensions:

int matrix[2][3] = { {1, 4, 2}, {3, 6, 8} };

matrix[0][0] = 9;

printf("%d", matrix[0][0]); // Now outputs 9 instead of 1
Output: 9
13/13

Loop Through a 2D Array 🔄

To loop through a multi-dimensional array, you need one loop for each of the array's dimensions.

Example 💻

The following example outputs all elements in the matrix array:

int matrix[2][3] = { {1, 4, 2}, {3, 6, 8} };

int i, j;

for (i = 0; i < 2; i++) {
  for (j = 0; j < 3; j++) {
    printf("%d ", matrix[i][j]);
  }
  printf("\n");
  }
}
Output:
1 4 2
3 6 8
💡 Nested Loops

The outer loop (i) controls the rows, while the inner loop (j) controls the columns within each row.

14/13

Three-Dimensional Arrays 📊

You can also declare arrays with more than two dimensions:

Example 💻

// A 3D array with 2 blocks, each with 4 rows and 3 columns
int example[2][4][3];
💡 Structure

This creates a 3D array with:

  • 2 blocks (first index)
  • 4 rows per block (second index)
  • 3 columns per row (third index)
15/13

When to Use Multidimensional Arrays 🎯

Multidimensional arrays are useful when your data is arranged in rows and columns, like a table, grid, or matrix.

📊

2D Arrays

Great for storing things like scores, game boards, or spreadsheets

📊

3D Arrays

Can represent more complex structures like a set of tables or levels in a game
