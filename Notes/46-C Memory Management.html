Memory in C 💾

Understanding how memory works in C is important for efficient programming. When you create a basic variable, C automatically reserves space for that variable.

📏� sizeof Operator Example 
// Different data types use different amounts of memory
int myInt;
float myFloat;
double myDouble;
char myChar;

printf("%zu\n", sizeof(myInt));      // 4 bytes
printf("%zu\n", sizeof(myFloat));    // 4 bytes
printf("%zu\n", sizeof(myDouble));   // 8 bytes
printf("%zu\n", sizeof(myChar));     // 1 byte

Why It's Important to Know

If you create a program that occupies too much, or unnecessary memory, it can result in slow and poor performance.

Static Memory 📊

Static memory is memory that is reserved for variables before the program runs. This is also known as compile-time memory allocation.

📝 Example 
// Static array allocation
int students[20];
printf("%zu", sizeof(students)); // 80 bytes (20 * 4)

C automatically reserves space for 20 elements (80 bytes), but if only 12 students attend, 8 elements (32 bytes) are unused.

Limitations of Static Memory

  • Cannot change size after compilation
  • May waste memory if actual usage is less than allocated
  • Not flexible for varying data sizes
5/10

Dynamic Memory 🔄

Dynamic memory is allocated after the program starts running, giving you full control over memory usage.

📝 Memory Allocation Functions 
// Dynamic allocation with malloc
int *ptr1 = malloc(20 * sizeof(int));

// Dynamic allocation with calloc
int *ptr2 = calloc(20, sizeof(int));

// Both allocate 80 bytes (20 * 4)

malloc() allocates memory but doesn't initialize it.

calloc() allocates memory and initializes all bytes to zero.

Benefits of Dynamic Memory

  • Allocate only what you need
  • Can resize as needed
  • More efficient for varying data sizes

Stack Memory 📚

Stack memory is a type of dynamic memory reserved for variables declared inside functions.

📝 Function Call Stack 
void function1() {
  int localVar = 10;
  // Local variable on stack
  // Stack memory is allocated here
}

void function2() {
  int localVar2 = 20;
  // New stack frame
}

When a function is called, stack memory is allocated for its variables. When the function returns, the stack memory is freed.

Stack Overflow

Recursion that repeats itself too many times may take up too much stack memory, causing a stack overflow.

Memory Allocation Functions 🔧

C provides functions to allocate and deallocate dynamic memory:

🔧

malloc()

Allocates memory but doesn't initialize

🔧

calloc()

Allocates and initializes to zero

🔧

free()

Releases allocated memory

🔄

realloc()

Resizes allocated memory

📝 Example 
// Allocate memory for an integer
int *ptr = malloc(sizeof(int));

// Allocate and initialize an array
int *arr = calloc(10, sizeof(int));

// Free memory when done
free(ptr);
free(arr);

Always free memory when you're done with it to avoid memory leaks.

Proper Use of sizeof with Pointers 🔍

When working with pointers and dynamic memory, it's important to use sizeof correctly:

📝 Correct Usage 
// Allocate memory for an integer
int *ptr = malloc(sizeof(int));

// Allocate memory for an array
int *arr = calloc(10, sizeof(int));

Using sizeof(*ptr) instead of sizeof(ptr) ensures you're allocating the correct amount of memory for the data type.

Common Mistake

// This measures the pointer itself (usually 8 bytes)
int size = sizeof(ptr); // Wrong!

// This measures the data type pointed to (usually 4 bytes)
int size = sizeof(int); // Correct!

Always use sizeof(*ptr) when allocating memory for a pointer to a data type.

Example: Dynamic Memory Allocation 👥

Let's improve the students array example with dynamic memory:

📝 Dynamic Students Array 
#include <stdio.h>
#include <stdlib.h>

int main() {
  // Get number of students from user
  int numStudents;
  printf("Enter number of students: ");
  scanf("%d", &numStudents);
  
  // Allocate memory for students array
  int *students = calloc(numStudents, sizeof(int));
  
  // Fill with student data
  for (int i = 0; i < numStudents; i++) {
    // Fill with student data here
  }
  
  // Use the array
  // Free memory when done
  free(students);
  
  return 0;
}

This approach allocates exactly the amount of memory needed, avoiding waste.
