Understanding fixed iteration loops in C programming ⏱️

When you know exactly how many times you want to loop through a block of code, use the for loop 🔢

For Loop 🔄

When you know exactly how many times you want to loop through a block of code, use the for loop instead of a while loop:

Syntax 📝

for (expression 1; expression 2; expression 3) {
  // code block to be executed
}

Expressions Explained 🔍

  • Expression 1 is executed (one time) before the execution of the code block.
  • Expression 2 defines the condition for executing the code block.
  • Expression 3 is executed (every time) after the code block has been executed.
2/10

Print Numbers 🔢

The example below will print the numbers 0 to 4:

int i;

for (i = 0; i < 5; i++) {
  printf("%d\n", i);
}
Output:
0
1
2
3
4

Example Explained 📖

  • Statement 1 sets a variable before the loop starts: int i = 0
  • Statement 2 defines the condition for the loop to run: i < 5. If the condition is true, the loop will start over again, if it is false, the loop will end.
  • Statement 3 increases a value each time the code block in the loop has been executed: i++

Print Even Numbers ➡️

This example prints even values between 0 and 10 (inclusive):

int i;

for (i = 0; i <= 10; i = i + 2) {
  printf("%d\n", i);
}
Output:
0
2
4
6
8
10

Explanation 📖

In this example, we use a custom increment expression (i = i + 2) instead of the standard i++. This causes the loop to increment by 2 each time, resulting in only even numbers being printed.

Sum of Numbers ➕

This example calculates the sum of numbers from 1 to 5:

int sum = 0;
int i;

for (i = 1; i <= 5; i++) {
  sum = sum + i;
}

printf("Sum is %d", sum);
Output: Sum is 15

Explanation 📖

  • We initialize a sum variable with value 0
  • The for loop iterates from 1 to 5
  • In each iteration, we add the current value of i to sum
  • After the loop completes, we print the final sum (1+2+3+4+5 = 15)

Countdown ⏱️

This example prints a countdown from 5 to 1:

int i;

for (i = 5; i > 0; i--) {
  printf("%d\n", i);
}
Output:
5
4
3
2
1

Explanation 📖

In this example, we use a decrement operator (i--) instead of the standard i++. This causes the loop to count down from 5 to 1, printing each value along the way.

Nested Loops 🔄🔄

It is also possible to place a loop inside another loop. This is called a nested loop.

How Nested Loops Work 🔍

The "inner loop" will be executed one time for each iteration of the "outer loop":

🔄

Outer Loop

Controls the number of times the inner loop runs

🔄

Inner Loop

Runs completely for each iteration of the outer loop

📊

Use Cases

Tables, matrices, or multi-dimensional data

7/10

Nested Loops Example 🔄🔄

int i, j;

// Outer loop
for (i = 1; i <= 2; ++i) {
  printf("Outer: %d\n", i); // Executes 2 times

  // Inner loop
  for (j = 1; j <= 3; ++j) {
    printf(" Inner: %d\n", j); // Executes 6 times (2 * 3)
  }
}
Output:
Outer: 1
  Inner: 1
  Inner: 2
  Inner: 3
Outer: 2
  Inner: 1
  Inner: 2
  Inner: 3

Explanation 📖

  • The outer loop runs twice (for i = 1 and i = 2)
  • For each iteration of the outer loop, the inner loop runs three times (for j = 1, 2, and 3)
  • This results in a total of 6 inner loop iterations (2 × 3)

Multiplication Table Example ✖️

This example uses nested loops to print a simple multiplication table (1 to 3):

int i, j;

for (i = 1; i <= 3; i++) {
  for (j = 1; j <= 3; j++) {
    printf("%d ", i * j);
  }
  printf("\n");
}
Result:
1 2 3
2 4 6
3 6 9

Explanation 📖

  • The outer loop (i) represents the multiplicand (1, 2, 3)
  • The inner loop (j) represents the multiplier (1, 2, 3)
  • For each pair, we print the product (i × j)
  • A newline is printed after each row of the table

Real-Life Examples 🌍

Counting by Tens 🔢

To demonstrate a practical example of a for loop, let's create a program that counts to 100 by tens:

for (i = 0; i <= 100; i += 10) {
  printf("%d\n", i);
}

Printing Even Numbers ➡️

In this example, we create a program that only prints even numbers between 0 and 10 (inclusive):

for (i = 0; i <= 10; i = i + 2) {
  printf("%d\n", i);
}

Printing Odd Numbers 🔢

Here we only print odd numbers:

for (i = 1; i < 10; i = i + 2) {
  printf("%d\n", i);
}

Printing Powers of 2 🔢

In this example, we print the powers of 2 up to 512:

for (i = 2; i <= 512; i *= 2) {
  printf("%d\n", i);
}

Multiplication Table ✖️

And in this example, we create a program that prints a multiplication table for a specified number:

int number = 2;
int i;

// Print the multiplication table for the number 2
for (i = 1; i <= 10; i++) {
  printf("%d x %d = %d\n", number, i, number * i);
}

return 0;

For loops are powerful tools for iterating a known number of times! ⚡
They provide a clean, concise way to repeat code with precise control.
