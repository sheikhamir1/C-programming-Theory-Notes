Memory Management Overview 📚

Why Memory Management Matters

Memory management is a critical aspect of C programming that allows you to:

  • Allocate memory at runtime based on program needs
  • Resize memory blocks as requirements change
  • Free memory when it's no longer needed
  • Prevent memory leaks and optimize resource usage

Access Dynamic Memory 🔍

How Dynamic Memory Works

Dynamic memory behaves like an array, with its data type specified by the type of the pointer.

As with arrays, to access an element in dynamic memory, refer to its index number:

ptr[0] = 12;

You can also dereference the pointer to access the first element:

*ptr = 12;
💡
Key Point
Dynamic memory is accessed just like arrays, using either index notation or pointer dereferencing.
3/15

Access Dynamic Memory Example 💻

Reading from and Writing to Dynamic Memory

// Allocate memory
int *ptr;
ptr = calloc(4, sizeof(*ptr));

// Write to the memory
*ptr = 2;
ptr[1] = 4;
ptr[2] = 6;

// Read from the memory
printf("%d\n", *ptr);
printf("%d %d %d", ptr[1], ptr[2], ptr[3]);

Output:

2

4 6 0

Data Types in Dynamic Memory 🏷️

A Note About Data Types

Dynamic memory does not have its own data type, it is just a sequence of bytes. The data in the memory can be interpreted as a type based on the data type of the pointer.

In this example a pointer to four bytes can be interpreted as one int value (4 bytes) or as an array of 4 char values (1 byte each).

4 bytes

01010100

11010110

10101011

00110101

→

As int (4 bytes)

1684234849

→

As char[4] (1 byte each)

'T' 'Þ' '«' '5'

Data Types Example 🔄

Interpreting Memory with Different Data Types

int *ptr1 = malloc(4);
char *ptr2 = (char*) ptr1;
ptr1[0] = 1684234849;
printf("%d is %c %c %c %c", *ptr1, ptr2[0], ptr2[1], ptr2[2], ptr2[3]);

Output:

1684234849 is T Þ « 5

💡
Understanding the Example
The same memory block is interpreted differently based on the pointer type. As an int, it's a single value. As a char array, it's four separate characters.

Reallocate Memory 🔄

Changing Memory Size

If the amount of memory you reserved is not enough, you can reallocate it to make it larger.

Reallocating reserves a different (usually larger) amount of memory while keeping the data that was stored in it.

You can change the size of allocated memory with the realloc() function.

The realloc() function takes two parameters:

int *ptr2 = realloc(ptr1, size);
  • The first parameter is a pointer to the memory that is being resized
  • The second parameter specifies the new size of allocated memory, measured in bytes
7/15

Reallocate Memory Example 📊

Increase the Size of Allocated Memory

int *ptr1, *ptr2, size;

// Allocate memory for four integers
size = 4 * sizeof(*ptr1);
ptr1 = malloc(size);

printf("%d bytes allocated at address %p \n", size, ptr1);

// Resize the memory to hold six integers
size = 6 * sizeof(*ptr1);
ptr2 = realloc(ptr1, size);

printf("%d bytes reallocated at address %p \n", size, ptr2);
Initial allocation:
4 integers
After reallocation:
6 integers

NULL Pointer & Error Checking ⚠️

Handling Reallocation Failures

The realloc() function returns a NULL pointer if it is not able to allocate more memory. This is very unlikely, but it is worth keeping in mind when you need your code to be failproof.

The following example checks whether realloc() is able to resize the memory or not, by checking for a NULL pointer:

💡
Best Practice

You should always include error checking (if pointer == NULL) when allocating memory.

🗑️
Memory Cleanup

You should also always free, or release, allocated memory when you are done using it.

NULL Pointer Example 🔍

Check for a NULL Pointer

int *ptr1, *ptr2;

// Allocate memory
ptr1 = malloc(4);

// Attempt to resize the memory
ptr2 = realloc(ptr1, 8);

// Check whether realloc is able to resize the memory or not
if (ptr2 == NULL) {
  // If reallocation fails
  printf("Failed. Unable to resize memory");
} else {
  // If reallocation is successful
  printf("Success. 8 bytes reallocated at address %p \n", ptr2);
  ptr1 = ptr2; // Update ptr1 to point to the newly allocated memory
}
🗑️
Freeing Memory
To free memory, simply use the free() function: free(ptr1);

Deallocate (Free) Memory 🗑️

Releasing Memory When Done

When you no longer need a block of memory you should deallocate it. Deallocation is also referred to as "freeing" the memory.

Dynamic memory stays reserved until it is deallocated or until the program ends.

Once the memory is deallocated it can be used by other programs or it may even be allocated to another part of your program.

To deallocate memory, use the free() function:

free(pointer);

The pointer parameter is a pointer to the address of the memory to be deallocated.

💡
Good Practice

It is considered a good practice to set a pointer to NULL after freeing memory so that you cannot accidentally continue using it.

11/15

Deallocate Memory Example 💻

Working Example with Error Checking and Freeing

int *ptr;
ptr = malloc(sizeof(*ptr)); // Allocate memory for one integer

// If memory cannot be allocated, print a message and end the main() function
if (ptr == NULL) {
  printf("Unable to allocate memory");
  return 1; // Exit the program with an error code
}

// Set the value of the integer
*ptr = 20;

// Print the integer value
printf("Integer value: %d\n", *ptr);

// Free allocated memory
free(ptr);

// Set the pointer to NULL to prevent it from being accidentally used
ptr = NULL;

Memory Leaks 💧

What Are Memory Leaks?

A memory leak happens when dynamic memory is allocated but never freed.

If a memory leak happens in a loop or in a function that is called frequently it could take up too much memory and cause the computer to slow down.

There is a risk of a memory leak if a pointer to dynamic memory is lost before the memory can be freed. This can happen accidentally, so it is important to be careful and keep track of pointers to dynamic memory.

🔄

Pointer Overwritten

When a pointer is reassigned before freeing the original memory

🔒

Function Scope

When memory is allocated in a function but not freed before returning

❌

Failed Reallocation

When realloc() fails and the original pointer is lost

13/15

Memory Leaks Examples 💻

Example 1: Pointer Overwritten

int x = 5;
int *ptr;
ptr = calloc(2, sizeof(*ptr));
ptr = &x;

In this example, after the pointer is changed to point at x, the memory allocated by calloc() can no longer be accessed.

Example 2: Pointer Exists Only Inside a Function

void myFunction() {
  int *ptr;
  ptr = malloc(sizeof(*ptr));
}

int main() {
  myFunction();
  printf("The function has ended");
  return 0;
}

In this example, the memory that was allocated inside of the function remains allocated after the function ends but it cannot be accessed anymore.

Summary 📝

Best Practices for Memory Management in C

  • Remember to check for errors (NULL return values) to find out if memory allocation was successful or not
  • Prevent memory leaks - always remember to free memory that is no longer used, or else the program might underperform or even worse, crash if it runs out of memory
  • Set the pointer to NULL after freeing memory so that you cannot accidentally continue using it
✅

Do

Check for NULL after allocation

Free memory when done

Set pointer to NULL after freeing

❌

Don't

Assume allocation always succeeds

Forget to free allocated memory

Use freed memory
