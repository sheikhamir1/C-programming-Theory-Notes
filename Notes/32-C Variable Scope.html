1/8

Scope 🌐

Now that you understand how functions work, it is important to learn how variables act inside and outside of functions.

In C, variables are only accessible inside the region they are created. This is called scope.

Global Scope

Variables accessible throughout the program

Local Scope

Variables accessible only within a specific function

💡 Key Concept

Scope determines where in your program a variable can be accessed. Variables are only visible within the scope where they are defined.

2/8

Local Scope 🏠

A variable created inside a function belongs to the local scope of that function, and can only be used inside that function:

void myFunction() {
  // Local variable that belongs to myFunction
  int x = 5;

  // Print variable x
  printf("%d", x);
}

int main() {
  myFunction();
  return 0;
}

Output: 5

myFunction()
int x = 5; (accessible here)
📌 Remember

A local variable cannot be used outside the function it belongs to.

3/8

Local Scope Error ❌

If you try to access a local variable outside the function it belongs to, an error occurs:

void myFunction() {
  // Local variable that belongs to myFunction
  int x = 5;
}

int main() {
  myFunction();

  // Print variable x in main function
  printf("%d", x);
  return 0;
}

Compilation Error: 'x' undeclared (first use in this function)

myFunction()
int x = 5; (accessible here)
main()
x (not accessible here)
4/8

Global Scope 🌍

A variable created outside of a function is called a global variable and belongs to the global scope.

Global variables are available from within any scope, global and local:

// Global variable x
int x = 5;

void myFunction() {
  // We can use x here
  printf("%d", x);
}

int main() {
  myFunction();

  // We can also use x here
  printf("%d", x);
  return 0;
}

Output: 5

Output: 5

Global Scope
int x = 5; (accessible everywhere)
myFunction()

Can access x here

main()

Can also access x here

5/8

Naming Variables 🏷️

If you operate with the same variable name inside and outside of a function, C will treat them as two separate variables; one available in the global scope (outside function) and one available in the local scope (inside function):

// Global variable x
int x = 5;

void myFunction() {
  // Local variable with the same name as global variable (x)
  int x = 22;
  printf("%d\n", x); // Refers to local variable x
}

int main() {
  myFunction();

  printf("%d\n", x); // Refers to global variable x
  return 0;
}

Output: 22

Output: 5

Local Variable
int x = 22;

Used inside myFunction()

Global Variable
int x = 5;

Used outside functions

⚠️ Note

However, you should avoid using the same variable name for both globally and locally as it can lead to errors and confusion.

6/8

Global Variables Modification ✏️

In general, you should be careful with global variables, since they can be accessed and modified from any function:

// Global variable
int x = 5;

void myFunction() {
  printf("%d\n", ++x); // Increment value of x by 1 and print it
}

int main() {
  myFunction();

  printf("%d\n", x); // Print the global variable x
  return 0;
}

Output: 6

Output: 6

Global Scope
int x = 5; (initially)
myFunction()

Increments x to 6

main()

Prints x (now 6)

⚠️ Important

The value of x is now 6 (no longer 5) after being modified in myFunction(). This shows how global variables can be changed by any function.

7/8

Conclusion 📝

To sum up, use local variables (with good variable names) as much as you can. This will make your code easier to maintain and better to understand.

However, you may find global variables when working on existing C programs or while collaborating with others. Therefore, it is good to understand how scope works and how to use it effectively to make sure your code is clear and functional.

🏠

Local Variables

Use whenever possible for better code organization

🌍

Global Variables

Use sparingly and with clear naming

🏷️

Variable Names

Choose descriptive names to avoid confusion

🎯 Best Practices

  • Prefer local variables over global variables when possible
  • Use clear, descriptive variable names
  • Avoid using the same name for global and local variables
  • Be cautious when modifying global variables in functions
