Format Specifiers

Format specifiers are used together with the printf() function to tell the compiler what type of data the variable is storing. It is basically a placeholder for the variable value.

🔤
Structure of Format Specifiers

A format specifier starts with a percentage sign %, followed by a character.

Start
%
+
Character
d, f, c...
=
Result
%d, %f, %c
💡 Note

Format specifiers are essential for displaying variables correctly in C. Without them, the compiler doesn't know how to interpret the data you're trying to print.

2/7

Basic Format Specifiers

For example, to output the value of an int variable, use the format specifier %d surrounded by double quotes (""), inside the printf() function:

🔢 Integer Example
1int myNum = 15;
2printf("%d", myNum); // Outputs 15
15
🔤
Common Format Specifiers

To print other types, use %c for char and %f for float:

1// Create variables
2int myNum = 15; // Integer (whole number)
3float myFloatNum = 5.99; // Floating point number
4char myLetter = 'D'; // Character
5
6// Print variables
7printf("%d\n", myNum);
8printf("%f\n", myFloatNum);
9printf("%c\n", myLetter);
15
5.990000
D
3/7

Format Specifiers Reference

Here's a quick reference for the most common format specifiers in C:

Format Specifier Data Type Example
%d Integer (int) printf("%d", 15);
%f Floating point (float) printf("%f", 5.99);
%c Character (char) printf("%c", 'D');
%s String (char array) printf("%s", "Hello");
%lf Double (double) printf("%lf", 5.99);
💡 Note

You will learn more about Data Types in a later chapter.

4/7

Combining Text and Variables

To combine both text and a variable, separate them with a comma inside the printf() function:

📝 Single Variable Example
1int myNum = 15;
2printf("My favorite number is: %d", myNum);
My favorite number is: 15
📝
Multiple Variables

To print different types in a single printf() function, you can use the following:

1int myNum = 15;
2char myLetter = 'D';
3printf("My number is %d and my letter is %c", myNum, myLetter);
My number is 15 and my letter is D
💡 Tip

The order of variables in the printf() function must match the order of format specifiers in the string.

5/7

Print Values Without Variables

You can also just print a value without storing it in a variable, as long as you use the correct format specifier:

1printf("My favorite number is: %d", 15);
2printf("My favorite letter is: %c", 'D');
My favorite number is: 15
My favorite letter is: D
🔄
Variable vs. Direct Value

Let's compare the two approaches:

📦
Using Variables

Values are stored for later and can be re-used whenever needed

🔢
Direct Values

Values are used immediately and cannot be reused without retyping

💡 Best Practice

However, it is more sustainable to use variables as they are saved for later and can be re-used whenever.
