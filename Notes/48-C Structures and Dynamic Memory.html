Structures and Dynamic Memory 📚

Why Combine Structures with Dynamic Memory?

You can also use dynamic memory with structures. This is useful when you don't know how many structs you'll need in advance, or want to save memory by only allocating what's necessary.

For example, in a car dealership program where the number of cars is not fixed, dynamic memory allocation allows you to create a flexible data structure that can grow or shrink as needed.

🔄

Flexibility

Create data structures that can change size during runtime

💾

Memory Efficiency

Only allocate the memory you actually need

🚗

Real-World Applications

Perfect for applications with variable data sizes

Allocating Memory for a Struct 🏗️

Using malloc() with Structures

You can use the malloc() function to allocate memory for a struct pointer. This allows you to create structure instances dynamically at runtime.

The process is similar to allocating memory for primitive types, but you use sizeof(struct) to determine the size of memory needed.

Memory Request

malloc(sizeof(struct Car))

→

Allocated Memory

struct Car *

💡
Remember

Always check if malloc() returns NULL to handle allocation failures gracefully.

3/18

Struct Example 💻

Complete Example of Allocating Memory for a Struct

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Car {
  char brand[50];
  int year;
};

int main() {
  // Allocate memory for one Car struct
  struct Car *ptr = (struct Car*) malloc(sizeof(struct Car));

  // Check if allocation was successful
  if (ptr == NULL) {
    printf("Memory allocation failed.\n");
    return 1; // Exit the program with an error code
  }

  // Set values
  strcpy(ptr->brand, "Honda");
  ptr->year = 2022;

  // Print values
  printf("Brand: %s\n", ptr->brand);
  printf("Year: %d\n", ptr->year);

  // Free memory
  free(ptr);

  return 0;
}
4/18

Example Explained 🔍

Understanding the Code

  • malloc() allocates memory for one struct
  • strcpy() is used to copy a string into the brand field
  • We use -> to access members through the pointer
  • free() is used at the end to release the memory
💡
Important Note
malloc() allocates uninitialized memory. The content will be undefined until you assign values. If you want memory initialized to zero, you can use calloc().

Using Arrays of Structs 📊

Allocating Memory for Multiple Structs

You can also allocate memory for multiple structs at once, like an array. This is useful when you need to work with collections of structured data.

To allocate memory for an array of structs, you multiply the size of the struct by the number of elements you want:

struct Car *cars = (struct Car*) malloc(3 * sizeof(struct Car));

Memory Request

malloc(3 * sizeof(struct Car))

→

Allocated Memory

struct Car[3]

Arrays of Structs Example 🚗

Allocate Memory for 3 Cars

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Car {
  char brand[50];
  int year;
};

int main() {
  struct Car *cars = (struct Car*) malloc(3 * sizeof(struct Car));

  if (cars == NULL) {
    printf("Memory allocation failed.\n");
    return 1; // Exit the program with an error code
  }

  // Fill the data
  strcpy(cars[0].brand, "Ford");
  cars[0].year = 2015;

  strcpy(cars[1].brand, "BMW");
  cars[1].year = 2018;

  strcpy(cars[2].brand, "Volvo");
  cars[2].year = 2023;

  // Print the data
  for (int i = 0; i < 3; i++) {
    printf("%s - %d\n", cars[i].brand, cars[i].year);
  }

  free(cars);
  return 0;
}

Growing Arrays with realloc() 🔄

Resizing Dynamic Arrays of Structs

If you need more elements later, you can resize your dynamic array with realloc(). This may move the block to a new location and returns a new pointer.

Always store the result in a temporary pointer first to avoid losing the original memory if reallocation fails.

Initial Array

2 elements

→

Need More Space

Request 3 elements

→

Use realloc()

Resize to 3 elements

→

Expanded Array

3 elements

⚠️
Important

New space added by realloc() is uninitialized. Be sure to initialize newly added elements before using them.

8/18

realloc Example 🚗

Expand an Array of Structs

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Car {
  char brand[50];
  int year;
};

int main() {
  int count = 2;
  struct Car *cars = (struct Car*) malloc(count * sizeof(struct Car));
  if (cars == NULL) {
    printf("Initial allocation failed.\n");
    return 1;
  }

  // Initialize first 2 cars
  strcpy(cars[0].brand, "Toyota"); cars[0].year = 2010;
  strcpy(cars[1].brand, "Audi"); cars[1].year = 2019;

  // Need one more car -> grow to 3
  int newCount = 3;
  struct Car *tmp = (struct Car*) realloc(cars, newCount * sizeof(struct Car));
  if (tmp == NULL) {
    // 'cars' is still valid here; free it to avoid a leak
    free(cars);
    printf("Reallocation failed.\n");
    return 1;
  }
  cars = tmp; // use the reallocated block

  // Initialize the new element at index 2
  strcpy(cars[2].brand, "Kia");
  cars[2].year = 2022;

  // Print all cars
  for (int i = 0; i < newCount; i++) {
    printf("%s - %d\n", cars[i].brand, cars[i].year);
  }

  free(cars);
  return 0;
}

Real-Life Memory Management Example 📋

Creating a Dynamic List

To demonstrate a practical example of dynamic memory, we created a program that can make a list of any length.

Regular arrays in C have a fixed length and cannot be changed, but with dynamic memory we can create a list as long as we like:

List Structure

data int *
numItems int
size int
💡
Key Concept

The list structure contains all the information needed to manage a dynamic list: a pointer to the data, the current number of items, and the allocated capacity.

10/18

List Structure Code 💻

Defining the List Structure

struct list {
  int *data; // Points to the memory where the list items are stored
  int numItems; // Indicates how many items are currently in the list
  int size; // Indicates how many items fit in the allocated memory
};

void addToList(struct list *myList, int item);
📝
Structure Members Explained
  • data: A pointer to the dynamic memory which contains the contents of the list
  • numItems: Indicates the number of items that list has
  • size: Indicates how many items can fit in the allocated memory
💡
Pointers to Structures

This example uses a pointer to the structure myList. Because we are using a pointer to the structure instead of the structure itself, we use the arrow syntax (->) to access the structure's members.

The main() Function 🎯

Initializing the List

int main() {
  struct list myList;
  int amount;
  int i, j;

  // Create a list and start with enough space for 10 items
  myList.numItems = 0;
  myList.size = 10;
  myList.data = malloc(myList.size * sizeof(int));

  // Find out if memory allocation was successful
  if (myList.data == NULL) {
    printf("Memory allocation failed");
    return 1; // Exit the program with an error code
  }
🔍
Initialization Explained
  • myList.numItems is set to 0 because the list starts off empty
  • myList.size keeps track of how much memory is reserved (10 items)
  • We allocate memory and store a pointer to it in myList.data
  • We include error checking to verify allocation was successful

The addToList() Function ➕

Adding Items to the List

// This function adds an item to a list
void addToList(struct list *myList, int item) {

  // If the list is full then resize the memory to fit 10 more items
  if (myList->numItems == myList->size) {
    int newSize = myList->size + 10;

    // Use a temporary pointer so we don't lose the original on failure
    int *tmp = realloc(myList->data, newSize * sizeof(int));
    if (tmp == NULL) {
      printf("Memory resize failed\n");
      return; // Leave the list unchanged
    }

    // Only update fields after a successful reallocation
    myList->data = tmp;
    myList->size = newSize;
  }

  // Add the item to the end of the list
  myList->data[myList->numItems] = item;
  myList->numItems++;
}

addToList() Function Explained 🔍

How the Function Works

The addToList() function adds an item to the list. It takes two parameters:

  • A pointer to the list
  • The value to be added to the list

The function first checks if the list is full by comparing the number of items in the list to the size (capacity). If the list is full, it tries to grow the memory to fit 10 more items.

→

If full, resize

→

💡
Safety First

We use a temporary pointer with realloc so we don't lose the original block if the resize fails. We only update data and size after a successful resize.

Why Reserve 10 Items at a Time? ⚖️

Optimizing Memory Allocation

Optimizing is a balancing act between memory and performance. Even though we may be allocating some memory that we are not using, reallocating memory too frequently can be inefficient.

There is a balance between allocating too much memory and allocating memory too frequently.

🚀

Performance

Reserving memory in larger chunks reduces the frequency of reallocation operations

💾

Memory Usage

Allocating too much at once wastes memory that could be used by other parts of the program

💡
Finding the Right Balance
We chose the number 10 for this example, but it depends on how much data you expect and how often it changes. For example, if we know beforehand that we are going to have exactly 44 items then we can allocate memory for exactly 44 items and only allocate it once.

Complete Example 📋

Putting It All Together

#include <stdio.h>
#include <stdlib.h>

struct list {
  int *data;
  int numItems;
  int size;
};

void addToList(struct list *myList, int item);

int main() {
  struct list myList;
  int amount;
  int i, j;

  // Create a list and start with enough space for 10 items
  myList.numItems = 0;
  myList.size = 10;
  myList.data = malloc(myList.size * sizeof(int));

  // Find out if memory allocation was successful
  if (myList.data == NULL) {
    printf("Memory allocation failed");
    return 1;
  }

  // Add any number of items to the list
  amount = 44;
  for (i = 0; i < amount; i++) {
    addToList(&myList, i + 1);
  }

  // Display the contents of the list
  for (j = 0; j < myList.numItems; j++) {
    printf("%d ", myList.data[j]);
  }

  // Free the memory when it is no longer needed
  free(myList.data);
  myList.data = NULL;

  return 0;
}

// This function adds an item to a list
void addToList(struct list *myList, int item) {
  // If the list is full then resize the memory
  if (myList->numItems == myList->size) {
    int newSize = myList->size + 10;
    int *tmp = realloc(myList->data, newSize * sizeof(int));
    if (tmp == NULL) {
      printf("Memory resize failed\n");
      return;
    }
    myList->data = tmp;
    myList->size = newSize;
  }

  // Add the item to the end of the list
  myList->data[myList->numItems] = item;
  myList->numItems++;
}

Summary 📝

Key Takeaways

  • Structures can be combined with dynamic memory allocation to create flexible data structures
  • Use malloc() to allocate memory for structures and arrays of structures
  • Use realloc() to resize arrays of structures when needed
  • Always check for NULL after memory allocation
  • Remember to free memory when it's no longer needed
  • Find a balance between memory efficiency and performance when deciding how much memory to allocate at once
