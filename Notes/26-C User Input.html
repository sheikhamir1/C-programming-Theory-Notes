User Input 👤

You have already learned that printf() is used to output values in C.

To get user input, you can use the scanf() function:

2/9

Basic Input Example 💻

Output a number entered by the user:

Example 💻

// Create an integer variable that will store the number we get from the user
int myNum;


// Ask the user to type a number
printf("Type a number: \n");

// Get and save the number the user types
scanf("%d", &myNum);
Output: If user types 25, the program will store 25 in myNum
3/9

Understanding scanf() 🔍

The scanf() function takes two arguments: a format specifier of the variable, and a reference operator (&) which stores the memory address of the variable.

How scanf() Works 🧠

// The format specifier %d tells scanf to expect an integer
// The &myNum argument tells scanf where to store the input value
// The value at &myNum's memory address
💡 Memory Address

4/9

Multiple Inputs 📊

The scanf() function also allow multiple inputs (an integer and a character in the following example):

Example 💻

// Create an int and a char variable
int myNum;
char myChar;


// Ask the user to type a number AND a character and press enter: \n
// Get and save the number AND character the user types
scanf("%d %c", &myNum, &myChar);
Output: If user types 25 and 'J', the program will store 25 in myNum and 'J' in myChar
5/9

String Input 📝

You can also get a string entered by the user:

Example 💻

// Create a string variable
char firstName[30];


// Ask the user to input some text
printf("Enter your first name: \n");

// Get and save the text the user types
scanf("%s", firstName);
Output: If user types "John", the program will store "John" in firstName
6/9

fgets() for String Input 📝

However, scanf() has some limitations: it considers space (whitespace, tabs, etc.) as a terminating character, which means it can only display a single word (even if you type multiple words).

Alternative: fgets() 🔄

For reading entire lines of text, you can use the fgets() function. Note that you must include the following arguments: name of the string variable, sizeof(string_name), and stdin:

char fullName[30];


// Ask the user to input some text
printf("Type your full name: \n");

fgets(fullName, sizeof(fullName), stdin);
Output: If user types "John Doe", the program will store "John Doe" in fullName
7/9

String Input Limitations ⚠️

When working with strings in C, it's important to understand their limitations:

Fixed Size Arrays 📏�️

String arrays in C have a fixed size, which means you can't store more characters than the array was declared for. This can lead to buffer overflow if you try to store too much data.

Buffer Overflow ⚠️

If you try to store more characters than the array can hold, it can cause a buffer overflow, which may lead to security vulnerabilities or program crashes.

💡 Best Practice

Always ensure your string arrays are large enough to hold the maximum expected input, and consider using safer functions like fgets() instead of scanf().
