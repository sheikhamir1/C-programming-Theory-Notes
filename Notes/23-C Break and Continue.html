Controlling loop flow with break and continue statements 🔄

Break 🛑

You have already seen the break statement used in an earlier chapter of this tutorial. It was used to "jump out" of a switch statement.

Break in Loops ⏹️

The break statement can also be used to jump out of a loop.

Example 💻

This example stops the loop when i is equal to 4:

int i;

for (i = 0; i < 10; i++) {
  if (i == 4) {
    break;
  }
  printf("%d\n", i);
}
Output:
0
1
2
3

Explanation 📖

In this example, the loop iterates from 0 to 9, but when i reaches 4, the break statement is executed, causing the loop to exit immediately. This is why only numbers 0, 1, 2, and 3 are printed.

2/8

Continue ⏭️

The continue statement breaks one iteration (in the loop), if a specified condition occurs, and continues with the next iteration in the loop.

Example 💻

This example skips the value of 4:

int i;

for (i = 0; i < 10; i++) {
  if (i == 4) {
    continue;
  }
  printf("%d\n", i);
}
Output:
0
1
2
3
5
6
7
8
9

Explanation 📖

In this example, the loop iterates from 0 to 9, but when i reaches 4, the continue statement is executed. This causes the current iteration to end immediately and the loop to proceed to the next iteration. This is why the number 4 is not printed, but all other numbers from 0 to 9 are printed.

3/8

Combining Break and Continue 🔀

You can also combine break and continue.

Example 💻

This example skips printing 2 and stops the loop at 4:

int i;

for (i = 0; i < 6; i++) {
  if (i == 2) {
    continue;
  }
  if (i == 4) {
    break;
  }
  printf("%d\n", i);
}
Output:
0
1
3

Explanation 📖

  • When i is 0, it's printed normally
  • When i is 1, it's printed normally
  • When i is 2, the continue statement is executed, skipping the printf and moving to the next iteration
  • When i is 3, it's printed normally
  • When i is 4, the break statement is executed, causing the loop to exit completely

Break and Continue in While Loops 🔄

You can also use break and continue in while loops:

🛑

Break Example

Exits the loop when a condition is met

⏭️

Continue Example

Skips the current iteration and continues with the next

Break in While Loop 💻

int i = 0;

while (i < 10) {
  if (i == 4) {
    break;
  }
  printf("%d\n", i);
  i++;
}
Output:
0
1
2
3

Continue in While Loop 💻

int i = 0;

while (i < 10) {
  if (i == 4) {
    i++;
    continue;
  }
  printf("%d\n", i);
  i++;
}
Output:
0
1
2
3
5
6
7
8
9

Key Difference 🔍

Notice that in the continue example, we increment i before the continue statement to avoid an infinite loop. This is important because if we didn't increment i when i equals 4, the loop would continue checking if i equals 4 forever.

Good to Remember 💡

🛑

Break

Stops the loop completely

⏭️

Continue

Skips this round, but keeps looping

💡 Important Note

Both break and continue are powerful tools for controlling loop flow, but they should be used carefully to avoid confusion and unintended behavior in your programs.

Real-Life Example 🌍

Imagine processing a list of numbers where you want to skip negative values, but stop completely if you find a zero:

int myNumbers[] = {3, -1, 7, 0, 9};
int length = sizeof(myNumbers) / sizeof(myNumbers[0]);
int i;

for (i = 0; i < length; i++) {
  if (myNumbers[i] < 0) {
    continue; // skip negative numbers
  }
  if (myNumbers[i] == 0) {
    break; // stop loop when zero is found
  }
  printf("%d\n", myNumbers[i]);
}
Output:
3
7

Explanation 📖

  • The array contains the numbers 3, -1, 7, 0, and 9
  • The loop processes each element in the array
  • When it encounters -1, the continue statement skips it
  • When it encounters 0, the break statement stops the loop completely
  • Only 3 and 7 are printed before the loop stops
💡 Note

Don't worry if you don't fully understand the example above. It uses an array (int numbers[] = {3, -1, 7, 0, 9};) to store the numbers, and you will learn more about arrays in the next chapter.

Summary 📚

🔄

Loop Control

Key Points 🔑

  • Break immediately exits the loop when encountered
  • Continue skips the current iteration and moves to the next one
  • Both can be used in for and while loops
  • When using continue in while loops, be careful to modify the loop variable before continue to avoid infinite loops
  • These statements are useful for filtering data or handling special cases in loops

Break and continue statements give you precise control over loop execution! 🎮
Use them wisely to make your code more efficient and readable.
