Data Types

As explained in the Variables chapter, a variable in C must be a specified data type, and you must use a format specifier inside the printf() function to display it:

1// Create variables
2int myNum = 5; // Integer (whole number)
3float myFloatNum = 5.99; // Floating point number
4char myLetter = 'D'; // Character
5
6// Print variables
7printf("%d\n", myNum);
8printf("%f\n", myFloatNum);
9printf("%c\n", myLetter);
5
5.990000
D
💡 Note

Each data type requires a specific format specifier to display its value correctly. Using the wrong format specifier can lead to unexpected output or errors.

Basic Data Types

The data type specifies the size and type of information the variable will store.

In this tutorial, we will focus on the most basic ones:

Data Type Size Description Example
int 2 or 4 bytes Stores whole numbers, without decimals 1
float 4 bytes Stores fractional numbers, containing one or more decimals. Sufficient for storing 6-7 decimal digits 1.99
double 8 bytes Stores fractional numbers, containing one or more decimals. Sufficient for storing 15 decimal digits 1.99
char 1 byte Stores a single character/letter/number, or ASCII values 'A'

Basic Format Specifiers

There are different format specifiers for each data type. Here are some of them:

Format Specifier Data Type
%d or %i int
%f or %F float
%lf double
%c char
%s Used for strings (text), which you will learn more about in a later chapter
⚠️ Important

It is important that you use the correct format specifier for the specified data type. If not, the program may produce errors or even crash.

🔤
Format Specifier Examples
1int age = 25;
2float price = 19.99;
3double pi = 3.14159265359;
4char grade = 'A';
5
6printf("Age: %d years\n", age);
7printf("Price: $%.2f\n", price);
8printf("Pi: %.11lf\n", pi);
9printf("Grade: %c\n", grade);
Age: 25 years
Price: $19.99
Pi: 3.14159265359
Grade: A

C Character Data Types

The char Type

The char data type is used to store a single character.

The character must be surrounded by single quotes, like 'A' or 'c', and we use the %c format specifier to print it:

1char myGrade = 'A';
2printf("%c", myGrade);
A
🔤
ASCII Values

Alternatively, if you are familiar with ASCII, you can use ASCII values to display certain characters. Note that these values are not surrounded by quotes (''), as they are numbers:

1char a = 65, b = 66, c = 67;
2printf("%c", a);
3printf("%c", b);
4printf("%c", c);
ABC
ASCII Value Character ASCII Value Character
65 A 97 a
66 B 98 b
67 C 99 c

5/7

Notes on Characters

⚠️ Warning

If you try to store more than a single character, it will only print the last character:

1char myText = 'Hello';
2printf("%c", myText);
o
💡 Note

Don't use the char type for storing multiple characters, as it may produce errors.

Single Character (char)
char myLetter = 'A';
printf("%c", myLetter);
✅

Correct for single characters

VS
VS
Multiple Characters (string)
char myText[] = "Hello";
printf("%s", myText);
✅

Correct for multiple characters

💡 For Now

Just know that we use strings for storing multiple characters/text, and the char type for single characters.
